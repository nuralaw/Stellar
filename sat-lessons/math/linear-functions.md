## What this question looks like

A *function* is a rule that turns each input into exactly one output. A *linear* function changes its output by the same amount every time the input goes up by 1, so its graph is a straight line. It is written f(x) = mx + b, but the letters can change: C(t), P(n) or h(w).

On screen you will see a rule like f(x) = 4x − 9, a table of inputs and outputs, a graph of a line, or a short story about something that grows or shrinks at a steady rate: a phone plan, a draining tank, a savings account.

Common question stems:

- "What is the value of f(4)?"
- "For the function f, f(k) = 15. What is the value of k?"
- "Which equation defines f?"
- "What is the best interpretation of 35 in this context?"
- "For which table is y a linear function of x?"
- "The function g is defined by g(x) = f(x + 4) − 6. What is the value of g(0)?"

College Board does not publish a count for each skill. Algebra gives 13 to 15 of the 40 scored math questions, shared by five linear skills, so expect around three linear-function questions per test (our estimate). Many of them are set in a real-world context, and some are student-produced response (SPR) questions, where you type your own answer.

| Sub-type | What you do |
|---|---|
| Evaluate or solve | Put an input in, or set the rule equal to a given output |
| Build the rule | Find m and b from two points, a table, a graph or a story |
| Interpret | Say what m, b or a pair like f(8) = 900 means in the story |
| Read a graph | Read values and intercepts, using the axis scale carefully |
| Spot linear data | Check that the rate of change stays the same |
| Shift or combine | Work with f(x) + k, f(x + k) or two functions together |

## The method

1. **Name the input and the output, with units.** The input goes inside the parentheses. The output is the value of the function. In C(t), for example, t might be "hours" and C(t) "cost in dollars".
2. **Decide which job the question wants.** Use the table below: evaluate, solve, build or interpret.
3. **Find the slope** from two exact points: m = change in output ÷ change in input.
4. **Find the starting value b.** b = f(0). If no input of 0 is given, put one point into y = mx + b and solve for b.
5. **Answer the question that was asked.** They may want f(10), the input for an output, m + b, or a sentence about meaning.
6. **Check.** Test a third point from the table or graph, or ask whether your answer fits the story.

| Job | Clue in the question | What to do |
|---|---|---|
| Evaluate | "What is f(4)?" | Replace x with 4 and calculate |
| Solve | "f(k) = 15" or "When is the cost $90?" | Set the rule equal to the output and solve for the input |
| Build | a table, two points, a graph, or "starts at… and changes by… per…" | Slope first, then b |
| Interpret | "best interpretation of…" | Rate per one unit, or value when the input is 0 |

## Rules and formulas you need

None of this is on the test's reference sheet, so learn it by heart.

### Function notation

| You see | It means |
|---|---|
| f(3) | the output when the input is 3 (not f times 3) |
| f(3) = 10 | the point (3, 10) is on the graph of y = f(x) |
| f(x) = 10 | the output is 10, so solve for the input x |
| f(a + 1) | replace every x with (a + 1): m(a + 1) + b |
| f(0) | the y-intercept, b |
| f(5) − f(2) | 3m, because the input went up by 3 |

For example, if f(x) = 2x − 5, then f(a + 1) = 2(a + 1) − 5 = 2a − 3.

### Slope and starting value

- m = (y_2 − y_1)/(x_2 − x_1): change in output ÷ change in input. Subtract in the same order on top and bottom.
- b = f(0). From any point (x, y) on the line: b = y − mx.
- One point plus a rate: the rate is m. Put the point in to find b.
- In a story, the starting amount is b and the amount per unit is m. If the amount goes down over time, m is negative.
- If the line passes through (0, 0), then b = 0 and f(x) = mx. That is a proportional relationship.

### Is it linear?

- Linear means the rate (change in y ÷ change in x) is the same between every pair of neighboring rows.
- If the x-values go up in equal steps, the y-values must change in equal steps.
- If the x-steps are uneven, divide each change in y by its own change in x.
- If y is multiplied by the same number each step (2, 4, 8, 16), the function is exponential, not linear.
- A graph shows a linear function only if it is a straight line that is not vertical. A curve, or a line that bends, is not linear.

### What the numbers mean

| Part | Meaning | Sentence to look for |
|---|---|---|
| m | rate of change | "For each additional 1 [input unit], the [output] increases (or decreases) by m [output units]." |
| b | starting value | "The [output] when the [input] is 0." |
| f(a) = c | an input-output pair | "When the [input] is a, the [output] is c." |
| x-intercept | where the output is 0 | "The [input] at which the [output] reaches 0." |

> **Trap:** The number that stands alone is not always the value at input 0. In C(w) = 9 + 1.5(w − 2), the 9 is the cost when w − 2 = 0, which means w = 2. And if t counts years since 2015, the starting value is the value in 2015, not in year 0.

### Shifts

- f(x) + k adds k to every output, so the graph moves up k. The slope stays the same.
- f(x + k) adds k to the input first, then uses the rule, so the graph moves k units to the left. For example, g(x) = f(x + 4) gives g(0) = f(4).
- f(x + 4) is not the same as f(x) + 4.

## Worked examples

### Example 1: Output given, find the input

f(x) = (3/4)x + 6

For the function f defined above, f(k) = 15. What is the value of k?

- (A) 6.75
- (B) 12
- (C) 17.25
- (D) 28

**Solution.** f(k) = 15 means "the output is 15". So the input k is the unknown: (3/4)k + 6 = 15. Subtract 6: (3/4)k = 9. Multiply by the flipped fraction 4/3: k = 9 × 4/3 = 12. Check: (3/4)(12) + 6 = 9 + 6 = 15.

Choice (C) is f(15). It treats 15 as the input instead of the output. Choice (A) multiplies 9 by 3/4 instead of dividing by 3/4. Choice (D) adds 6 instead of subtracting it, which gives (3/4)k = 21.

**Answer:** (B)

### Example 2: Build the rule from a table

The table shows three values of x and the corresponding values of f(x) for the linear function f.

| x | f(x) |
|---|---|
| −2 | 13 |
| 1 | 4 |
| 6 | −11 |

What is the value of f(10)?

*Student-produced response: enter your answer.*

**Solution.** Slope from the first two rows: (4 − 13)/(1 − (−2)) = −9/3 = −3. Check it with the last two rows: (−11 − 4)/(6 − 1) = −15/5 = −3. The x-steps are different (3 and then 5), so each change in y must be divided by its own change in x. Don't compare −9 and −15 directly.

Find b with the point (1, 4): 4 = −3(1) + b, so b = 7. The rule is f(x) = −3x + 7, and f(10) = −30 + 7 = −23.

Faster: from x = 6 to x = 10 the input grows by 4, so the output changes by 4 × (−3) = −12. That gives −11 − 12 = −23. The answer is negative, so type the minus sign.

**Answer:** −23

### Example 3: Which table is linear?

For which of the following tables is y a linear function of x?

- (A) x-values 1, 2, 3, 4 with y-values 2, 4, 8, 16
- (B) x-values 0, 1, 3, 6 with y-values 2, 5, 11, 20
- (C) x-values 0, 2, 4, 6 with y-values 1, 4, 9, 16
- (D) x-values 1, 2, 3, 4 with y-values 10, 7, 5, 4

**Solution.** Find the rate between each pair of neighboring points.

- (A): the x-steps are all 1, but y changes by 2, then 4, then 8. Not constant. The y-values double, which is exponential.
- (B): y changes by 3, 6 and 9 while x changes by 1, 2 and 3. The rates are 3/1, 6/2 and 9/3, which are all 3. Linear: y = 3x + 2.
- (C): the x-steps are all 2, but y changes by 3, 5 and 7. Not constant.
- (D): the x-steps are all 1, but y changes by −3, −2 and −1. Not constant.

Many students reject (B) because y jumps by different amounts. But x also jumps by different amounts, and the rate is what counts.

**Answer:** (B)

### Example 4: Build a model from a story

A candle is 30 centimeters tall when it is lit. It burns at a constant rate, and 4 hours after it is lit, it is 24 centimeters tall. Which function gives the height h(t), in centimeters, of the candle t hours after it is lit?

- (A) h(t) = 24 − 1.5t
- (B) h(t) = 30 − 6t
- (C) h(t) = 30 − 1.5t
- (D) h(t) = 30 + 1.5t

**Solution.** The starting value is the height when t = 0, so b = 30. The rate: the height drops 30 − 24 = 6 centimeters in 4 hours, which is 6 ÷ 4 = 1.5 centimeters per hour. The height goes down, so m = −1.5. That gives h(t) = 30 − 1.5t. Check: h(4) = 30 − 6 = 24.

Choice (B) uses the 4-hour drop of 6 as if it were the drop in one hour. Choice (A) starts at 24, which is the height after 4 hours, not at the start. Choice (D) makes the candle grow.

**Answer:** (C)

### Example 5: Read the structure

A shipping company uses the function C(w) = 9 + 1.5(w − 2) to find the cost C(w), in dollars, to ship a package that weighs w pounds, where w ≥ 2. What is the best interpretation of 9 in this context?

- (A) The cost to ship a package that weighs 0 pounds is $9.
- (B) The cost to ship a package that weighs 2 pounds is $9.
- (C) The cost increases by $9 for each additional pound.
- (D) The cost increases by $9 for every 2 additional pounds.

**Solution.** The 9 stands alone, so it is the cost when the part in parentheses is 0. That happens when w − 2 = 0, so w = 2. Check: C(2) = 9 + 1.5(0) = 9. So $9 is the cost for a 2-pound package.

The rate is 1.5: each additional pound adds $1.50, and 2 additional pounds add $3, not $9. That rules out (C) and (D). Choice (A) is the classic trap. It reads 9 as the value at w = 0, but C(0) would be 9 + 1.5(−2) = 6, and the rule only allows w ≥ 2 anyway.

**Answer:** (B)

### Example 6: Shift the input

For the linear function f, f(2) = 11 and f(7) = 31. The function g is defined by g(x) = f(x + 4) − 6. What is the value of g(0)?

*Student-produced response: enter your answer.*

**Solution.** First build f. Slope: (31 − 11)/(7 − 2) = 20/5 = 4. Then b from the point (2, 11): 11 = 4(2) + b, so b = 3. The rule is f(x) = 4x + 3. Check with the other point: 4(7) + 3 = 31.

Now g(0) = f(0 + 4) − 6 = f(4) − 6. Since f(4) = 4(4) + 3 = 19, g(0) = 19 − 6 = 13.

Two common mistakes: adding 4 to the output instead of the input, f(0) + 4 − 6 = 3 + 4 − 6 = 1, and ignoring the + 4 completely, f(0) − 6 = −3.

**Answer:** 13

## Traps to avoid

- **Mixing up input and output.** f(k) = 15 says the output is 15. Plugging in 15 as the input gives f(15), a planted wrong answer.
- **Reading f(3) as "f times 3".** f(3) is one number: the output for the input 3.
- **Slope upside down.** Slope is change in output ÷ change in input, not the other way around.
- **Using a table value as b.** b is the output at x = 0 only. A row like (1, 4) does not make b = 4.
- **Comparing raw y-changes when the x-steps are uneven.** Divide each change in y by its own change in x first.
- **Calling doubling "linear".** Equal ratios (2, 4, 8, 16) mean exponential growth, not linear growth.
- **Treating a total change as the rate.** "It drops 6 cm in 4 hours" means 1.5 cm per hour, not 6.
- **Forgetting the sign.** Anything that falls, drains or loses value has a negative slope.
- **Swapping the meanings of slope and intercept.** In the answer choices, one usually describes the rate and another the starting value. Match each number to its job.
- **Assuming the constant is the value at 0.** In forms like 9 + 1.5(w − 2), or when t means "years since 2015", find out which input makes the variable part 0.
- **Treating f(x + 4) like f(x) + 4.** The first changes the input, the second changes the output.
- **Ignoring units.** If the output is in thousands of dollars, a slope of 2.5 means $2,500 per unit, not $2.50.

## Desmos shortcut

**Evaluate and solve.** Type `f(x)=0.75x+6` on line 1. On line 2, type `f(15)`, and Desmos shows 17.25. To solve f(k) = 15 instead, add `y=15`, zoom out (the crossing is outside the normal view) and click the point where the two lines cross: (12, 15), so k = 12. Decimals like 0.75 are safer to type than fractions. If you do type a fraction, press the right arrow key (→) to leave the denominator.

**Table to rule.** Click the + button and choose "table". Enter the inputs in the x_1 column and the outputs in the y_1 column. On a new line, type `y1~mx1+b`, using ~ (the tilde key), not =. Desmos turns each 1 into a small subscript by itself; don't type an underscore, or the ~ gets stuck in the subscript and you get an error. For Example 2, Desmos shows m = −3 and b = 7, plus R² = 1, which means the points lie exactly on one line. Then type `10m+b` to get f(10) = −23.

**Linear or not?** Run the same regression on each table: R² = 1 only when the points lie exactly on a line. By hand, checking the rates is usually faster.

**Shifts and combinations.** Type `f(x)=4x+3`, then `g(x)=f(x+4)-6`, then `g(0)`. Desmos shows 13.

**Graphs.** When the question shows a graph, pick two points where the line crosses grid corners exactly. Type them into a table and use the regression above to get m and b.

Desmos cannot read a story for you. You still have to decide what the input and output are before you type anything.

## Quick checklist

- What are the input and the output, and what are their units?
- Is the given number an input (f of it) or an output (f equals it)?
- Did I find the slope as change in output ÷ change in input, from exact points?
- Is b really the output at input 0, or does the form hide a different starting point?
- Does the sign of my slope match the story (rising or falling)?
- Did I answer the exact question: f(10), an input, m + b, or a meaning?
- Did I test my rule on a second or third point?
