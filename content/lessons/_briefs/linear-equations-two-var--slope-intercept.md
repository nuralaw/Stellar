# linear-equations-two-var--slope-intercept

**Shows:** in \(y = mx + b\), \(b\) is where the line crosses the \(y\)-axis and \(m\) is how far it rises per 1 step right.

**Storyboard:**
1. Empty grid. \(y = 2x + 1\) appears at the top.
2. A dot lands on the \(y\)-axis at \((0, 1)\), labelled "\(b = 1\): start (0, 1)".
3. From the dot a slope triangle draws: 1 step right (bracket "run 1"), 2 steps up (bracket "rise 2"). The line is drawn through it. Label "\(m = 2\)".
4. Slider-like replay: \(b\) changes to \(-2\) (the whole line slides down, same tilt), then \(m\) changes to \(-1\) (the line tilts down, same crossing point). Equation text updates each time.

**Labels & formulas:** \(y = mx + b\), "start", "per 1 step right", \(y = 2x + 1\), \(y = 2x - 2\), \(y = -x - 2\).

**Stress:** \(b\) and its dot in one colour (accent), the slope triangle in a second tone; the unchanged part stays neutral while the other one moves. Keep integer grid labels ≥ 11 units.
