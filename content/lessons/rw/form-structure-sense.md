# Trap: one main verb
Count main verbs. Add one only if none exists.

## Is a main verb there?

The **subject** is who or what the sentence is about. Its **main verb** is what it does or is. A second main verb needs *and*.

```visual
form-structure-sense--verb-slot
```

```example
The dog ______ in the yard belongs to my neighbor.
Choices: barks / barking
1. Read on: belongs :: That is the main verb. The slot is full.
2. Core: The dog belongs to my neighbor. :: One subject, one main verb.
3. Answer: barking :: It only describes the dog.
```

```more
A **main verb** can be the verb of a full sentence: *belongs*, *is*, *opened*. Some forms only describe: *-ing* alone (*barking*), *to* + verb (*to repair*), and an *-ed* form right after a noun (*launched in 1990* means "that was launched"). They can join a sentence that already has a main verb. If there is no main verb yet, the blank must be one.
```

## An -ed form

```quiz
The telescope ______ in 1990 still sends back images.
* launched
- launches :: *Sends* is already the main verb. A second one breaks the sentence.
- has launched :: Also a main verb. The telescope cannot have two.
> The main verb is *sends*. *Launched in 1990* only describes the telescope.
```

## A to-form

```quiz
The city has the funds ______ the old bridge.
* to repair
- repairs :: *Has* is already the main verb. This would be a second one.
- repair :: Nothing joins it to the sentence. *To* does that job.
> *Has* is the main verb. *To repair the old bridge* describes the funds.
```

# Needs a main verb
No main verb yet? The blank must be one.

## Find the missing verb

Extra detail between commas never holds the main verb. Is there a main verb outside them? If not, the blank is the main verb.

```example
The bridge, which connects the two islands, ______ in 1932.
Choices: opened / opening / having opened
1. Subject: The bridge :: The extra part is between commas.
2. Main verb so far? None :: *Connects* is inside the extra part.
3. Answer: opened :: The blank must be the main verb.
```

```more
A phrase like *which connects the two islands* has its own verb, but it only describes the bridge. The sentence still needs a main verb for *The bridge*. *Opening* and *having opened* are describing forms. Only *opened* can be the main verb here.
```

## A verb is needed

```quiz
The new library, a gift from the town's founders, ______ over 5,000 books.
* holds
- holding :: It only describes. The library still needs a main verb.
- to hold :: It only describes. The library still needs a main verb.
> The extra part sits between commas. Nothing else is a main verb, so the blank must be one: *holds*.
```

# Match verb to subject
Find the true subject. Ignore the extras.

## Find the true subject

A verb matches its **subject**, not the nearest noun. Usually cross out *of* phrases and extras between commas.

```example
The box of old maps ______ dusty.
Choices: is / are
1. Cross out: of old maps :: Here the *of* phrase is an extra.
2. Left: The box ______ dusty. :: Read what is left.
3. box = one thing :: One thing takes a singular verb.
4. Answer: is
```

```more
Careful: after words like *some of*, *all of* and *half of*, the noun after *of* decides: *Some of the maps are dusty.* Also *A and B* is plural (*The box and the lamp are*). But *along with* and *as well as* only add an extra.
```

## Extras between commas

```quiz
The lead scientist, along with two graduate students, ______ the glacier every summer.
* visits
- visit :: *Along with* adds an extra, not a second subject.
- are visiting :: Plural. The subject is one scientist.
> Cross out the part between the commas: "The lead scientist visits the glacier."
```

# Late subjects, groups
Flip the sentence. A group is one thing.

## Flip the sentence

Sometimes the verb comes first. Flip the sentence to find the subject. *A and B* is plural.

```example
Beside the lake ______ a cabin and a boathouse.
Choices: stands / stand
1. Flip: "A cabin and a boathouse ______ beside the lake" :: Put the subject first.
2. cabin **and** boathouse = two things :: *And* joins two things.
3. Answer: stand :: Two things take a plural verb.
```

```more
In flipped sentences the subject comes after the verb, often after a place phrase (*Beside the lake*, *Among the findings*). Move the subject to the front to hear the right verb. **Group nouns** (*team*, *board*, *jury*, *class*) name one group made of many people and take a singular verb: *The team is ready.*
```

## A group is one

```quiz
The school board ______ meeting tonight to vote on its budget.
* is
- are :: A board is one group. The later word *its* shows one.
> *Board* names one group, like *team* or *jury*. One group takes *is*.
```

# Tense follows the clues
Dates and perfect tenses set the time.

## Since means has

Dates set the tense. *Since 2010* runs up to now: *has/have* + past participle. *Had* + participle: before another past event.

```example
Since 2010, the museum ______ over a million visitors.
Choices: welcomes / has welcomed / welcomed
1. Clue: Since 2010 :: From the past up to now.
2. Now is included :: Not a finished past event.
3. Answer: has welcomed :: *Has* + past participle.
```

```more
A **past participle** is the form after *has*, *have* or *had*: *welcomed*, *taken*, *gone*. **Has/have** + participle: from the past up to now. **Had** + participle: one past event before another. Other clues: *last year* is past, *next year* is future, *every day* is present.
```

## Before another past time

```quiz
Before the storm hit on Tuesday, the crew ______ the ship to a safe harbor.
* had moved
- has moved :: *Has* links the past to now. The storm is over.
- will move :: Future. But the storm already hit.
> The move came before the storm, and both are in the past. Earlier past: *had* + participle.
```

## Books use the present

Writing about a book or a general truth? Use the present tense.

```quiz
In Pride and Prejudice, Elizabeth Bennet ______ Mr. Darcy at first, but she later changes her mind.
* dislikes
- disliked :: Stories are told in the present, like *changes*.
- had disliked :: *Had* shows an earlier past. This story is told in the present.
> About a book or film, use the present tense. *Changes* is present, so the blank is present.
```

# Opening phrase, next noun
The opening phrase describes the noun right after it.

## Ask the phrase

An opening phrase describes the first noun after the comma. That noun must be the thing it describes.

```example
Reading the letter, ______
Choices: Maya began to smile. / a smile spread across Maya's face.
1. Ask: who was reading the letter? :: Maya. A smile can't read.
2. Maya comes right after the comma :: The phrase describes the next noun.
3. Answer: Maya began to smile.
```

```more
A **modifier** is a word or phrase that describes something. If the wrong noun follows the comma, the modifier *dangles*: *Reading the letter, a smile spread across Maya's face* says the smile was reading. Always ask: who or what does the opening phrase describe?
```

## Who was raised there?

```quiz
Raised in a fishing village in Chile, ______
- the poet's early work is full of images of the sea. :: The noun is *work*. Work wasn't raised anywhere.
- images of the sea fill the poet's early work. :: This says the images were raised in a village.
* the poet filled her early work with images of the sea.
> Who was raised in the village? The poet. So *the poet* comes right after the comma.
```

# Plural or possessive
's, s', or just s? Count the owners.

## The apostrophe grid

One owner: add 's. Several owners ending in s: add ' after the s. Just more than one: no apostrophe.

```visual
form-structure-sense--apostrophes
```

```example
The two ______ lockers are on the second floor.
Choices: students / student's / students'
1. "Two" → more than one owner :: The lockers belong to them.
2. Owning needs an apostrophe :: Plain *students* only counts.
3. Answer: students' :: Several owners: apostrophe after s.
```

```more
**Plural** means more than one: *girls*. **Possessive** shows who owns something: *the girl's book*. A plural that does not end in s adds 's: *children's books*. Owning pronouns (*its*, *their*, *whose*) never take an apostrophe, and they match their noun: one library, *its*; two libraries, *their*. *It's* means *it is*.
```

## Pick the pronoun

```quiz
The city library reopened ______ rooftop garden after a year of repairs.
- it's :: That reads "reopened it is rooftop garden."
* its
- their :: Plural. A library is one thing.
- they're :: Means *they are*: plural, and not owning.
> One library owns the garden: singular and owning, so *its*.
```

## Whose recipes?

```quiz
The Rivera sisters opened a bakery in 2019 and have since added a second shop. Both ______ recipes come from their grandmother, who taught them to bake in her small kitchen in Valencia.

Which choice completes the text so that it conforms to the conventions of Standard English?
* sisters'
- sister's :: This means one sister. The text says both.
- sisters :: Plural only. The recipes belong to them, so add '.
- sisters's :: This form is not standard English.
> Both sisters own the recipes: several owners ending in s, so the apostrophe goes after the s.
```
