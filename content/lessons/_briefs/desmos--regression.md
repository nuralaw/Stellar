# desmos--regression

**Shows:** points go into a table with columns x1 and y1, a model typed with ~ makes Desmos find the constants, and the fitted curve passes through every point.

**Storyboard:**
1. A two-column table appears with headers "x1" and "y1" and rows (1, 7), (3, 13), (4, 16). The points appear as dots on a grid.
2. A text line is typed letter by letter: `y1 ~ m x1 + b`. A tag "~ means: find the constants" sits beside the tilde; a crossed-out version `y1 = m x1 + b` carries the note "= needs known numbers".
3. A line is drawn through the dots and the constants appear in a small box: "m = 3, b = 4".
4. A second row of three mini-cards: "line: 2 points", "exponential: 2 points", "quadratic: 3 points", each with a tiny curve icon.
5. Last frame: the final equation \(y = 3x + 4\) beside the table.

**Labels & formulas:** "x1", "y1", `y1 ~ m x1 + b`, `y1 ~ a b^x1`, `y1 ~ a x1^2 + b x1 + c`, "m = 3", "b = 4", \(y = 3x + 4\), "2 points", "3 points".

**Stress:** the tilde (accent colour) as the key symbol; the fitted line going through all the dots. The model cards must stay readable on a phone (font at least 12). Show the names x1 and y1 in code style so they look different from x and y.
