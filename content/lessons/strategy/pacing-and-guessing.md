# Know your budget
71 s per question in R&W, 95 s in Math.

## Seconds per question

**Module time ÷ questions = your budget per question.**

```example
Math: 22 questions in 35 minutes. Reading and Writing (R&W): 27 questions in 32 minutes. How long per question?
1. Math: 35 × 60 = 2,100 s :: Minutes to seconds.
2. 2,100 ÷ 22 ≈ 95 s :: Divide by the questions.
3. R&W: 1,920 ÷ 27 ≈ 71 s :: 32 × 60 = 1,920.
4. Math 95 s, R&W 71 s
```

```more
A **module** is one timed part of the test. Each section has two modules. Each module has its own timer. These budgets are averages: easy questions should take less time, and hard questions more.
```

## Check your pace

Check your pace at any time: **time left ÷ questions left.** Below your budget? You are behind.

```quiz
Math module, 22 questions. 17 minutes are left and you're starting question 9. Where do you stand?
- On pace: about half the time is left :: Half the time is left, but 14 of 22 questions remain.
* Behind: 14 harder questions, about 73 s each
- Ahead: the hardest questions are already done :: Math runs from easier to harder.
> 17 min = 1,020 s. 1,020 ÷ 14 ≈ 73 s, under 95 s. The hardest questions are still ahead.
```

```more
"Questions left" includes the question you are on. At question 9 of 22: 22 − 8 = 14 questions. Time left: 17 × 60 = 1,020 seconds. Divide: about 73 seconds each. That is below the 95-second budget, and the hardest questions are still to come.
```

# Stuck: guess, flag, move
Budget spent and no plan? Move on.

## Stuck on question 9

A wrong answer costs nothing. A stuck question costs time.

```example
Math, question 9. You've spent 95 seconds and still have no plan.
1. 95 s = the whole budget :: More time here steals from other questions.
2. Cross out impossible choices, pick one :: Any guess can score.
3. Flag it, go to question 10 :: Come back if time is left.
```

```more
To **flag** a question is to press Mark for Review. It puts a bookmark on the question so you can find it again in the question menu. A flag does not save an answer. That is why you pick a choice first.
```

## Two choices left

```quiz
R&W, question 5. After 2 minutes you're down to two choices and still unsure. Best move?
- Reread the passage until you're sure :: You are already far past the 71 s budget.
- Flag it and leave it unanswered for now :: A blank scores zero if you never get back.
* Pick one of the two, flag it, move on
> A 1-in-2 guess now. The flag lets you return if time is left.
```

## Hard ends the type

In R&W, each question type climbs easy to hard, then the next type starts easy. Conventions is one long climb.

```quiz
R&W question 11 is the hardest of its type. You've spent 90 seconds and you're unsure. Best move?
* Guess, flag it, and move on to the next type
- Spend three more minutes: later questions are harder :: The next type starts easy again.
- Leave it blank and move on :: A blank scores zero. A guess can score.
> A hard question at the end of a type is expensive. The next type restarts easy, so move on.
```

```more
R&W groups come in a fixed order: Craft and Structure, Information and Ideas, Standard English Conventions, then Expression of Ideas. In the first, second and last groups, each question type climbs from easy to hard and then restarts. Conventions is one long climb: there, the next question is usually not easier.
```

# Cross out, then guess
Fewer choices, better odds.

## Cross out first

Each impossible choice you cross out raises your odds.

```visual
pacing-and-guessing--cross-out
```

```more
A choice is impossible when it breaks a rule of the topic: a probability is never below 0 or above 1, and a length is never negative. Cross out two of four choices and your chance goes from 1 in 4 to 1 in 2. Rules like these can be checked in seconds.
```

## Your odds

```quiz
No time to solve it. A jacket is 20% off, then 8% tax is added. The final price is $259.20. Original-price choices: $207.36, $240, $300, $324. You cross out the impossible ones and guess. Your chance?
* 1 in 2
- 1 in 4 :: That is a blind guess. Two choices are impossible.
- 1 in 3 :: Two choices are impossible, not just one.
> The net change is ×0.8 × 1.08 = ×0.864, below 1. The original must be above $259.20: $300 or $324.
```

# Out of time: fill everything
Any answer beats a blank.

## One minute left

```example
1 minute left. Multiple-choice questions 20, 21 and 22 are blank. Each needs about 90 seconds.
1. 60 s < 90 s :: No time to solve even one.
2. Click a choice on all three :: Takes seconds.
3. Three 1-in-4 chances, not three zeros :: A blank never scores.
4. Then work on question 20 :: Solved it? Change the guess.
```

```more
**Multiple-choice** questions have four choices, A to D. There is no penalty for a wrong answer, so a guess can only help. Cross out what you can first. If you have no time, any letter is better than none.
```

## Thirty seconds left

```quiz
30 seconds left. Three multiple-choice questions have no answer. Best move?
* Click an answer on all three
- Solve the first one carefully :: That leaves two blanks: two sure zeros.
- Leave them blank; wrong answers lower your score :: There is no penalty for a wrong answer.
> Three guesses can still score. Three blanks can't.
```

## Typed answers too

Math also has typed answers with no choices. A blank scores zero there too, so type your best estimate.

```quiz
Math module, 15 seconds left. A typed-answer question has no choices and no answer yet. Best move?
* Type your best estimate
- Leave it blank: there are no choices to guess from :: A blank scores zero. An estimate can score.
- Use the time to check another question :: You cannot fix a blank by checking.
> You cannot cross out choices, but a number can still be right. Typing costs seconds.
```

# End of a module
No carry-over. Spend spare minutes on Check Your Work.

## Spare minutes

```example
R&W module 1: you finish with 4 minutes left. What can you do with them?
1. Each module has its own timer :: Spare time never moves to module 2.
2. You can't end a module early :: With standard time, the timer must finish.
3. Open Check Your Work :: It shows blank and flagged questions.
4. Fill blanks first, then recheck flags
```

```more
**Check Your Work** is the screen at the end of a module. You can go back to any question there until the time ends. The timer can be hidden, but it comes back when five minutes remain. Module 1 sets how hard module 2 is, so accuracy in module 1 matters.
```

## Blank before flag

```quiz
Check Your Work shows question 7 blank and question 19 flagged with an answer. You have 3 minutes. What do you do first?
* Answer question 7, then recheck question 19
- Recheck question 19 first :: It already has an answer. A blank is a sure zero.
- Submit now: one blank doesn't matter :: Every blank is a lost chance.
> A blank is worth zero. A guess on question 7 can score. Question 19 can wait.
```

# Trap: flagging a blank
A flag is a reminder, not an answer.

## Flag without a guess

```visual
pacing-and-guessing--flag-blank
```

```example
You flag question 14 without answering, planning to return. The timer hits 0:00 while you're on question 22.
1. Question 14: flagged, still blank :: A flag holds no answer.
2. 0:00 → the module closes :: You never got back.
3. Blank = zero :: A guess had a 1-in-4 chance.
4. Fix: enter a guess, then flag
```

```more
The flag is only a bookmark in the question menu. The test scores the answer you chose, not the flag. So the safe order is always: choose an answer first, then flag, then move on. At the end, check the flagged questions with the time you have left.
```

## Before you click Next

```quiz
Question 14 looks long. You want to skip it and return later. What do you do before clicking Next?
- Flag it and leave it unanswered :: Trap: if time runs out, the blank scores zero.
* Enter a guess, then flag it
- Write "14" on your scratch paper :: Still a blank. Enter a guess first.
> A guess costs seconds and can score. Change it if you get back.
```
