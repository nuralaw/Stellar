# Solve for x
Same move on both sides until x stands alone.

## Same move, both sides

Do the **same thing to both sides** until x stands alone.

```visual
linear-equations-one-var--balance
```

```example
3x + 2 = x + 8. Find x.
1. 2x + 2 = 8 :: Subtract x from both sides.
2. 2x = 6 :: Subtract 2 from both sides.
3. x = 3 :: Divide both sides by 2.
```

```more
A **variable** is a letter, like x, that stands for a number. An equation stays true when you do the same thing to both sides. First collect the x terms on one side. Then move the plain numbers to the other side. Last, divide to leave x alone.
```

## Solve it yourself

```quiz
5x − 4 = 2x + 11. What is the value of x?
answer: 5
- 15 :: That is 3x. Divide 15 by 3.
- 7/3 :: Add 4 to both sides: 11 + 4 = 15.
> Subtract 2x: 3x − 4 = 11. Add 4: 3x = 15. Divide by 3: x = 5.
~ type y=5x-4 :: Type each side as its own line.
~ type y=2x+11
~ zoom -2 10 -5 35
~ point (5, 21) :: Click the crossing. Its x is the answer: 5.
```

# Fractions and decimals
Multiply every term to clear the fractions.

## Clear the fractions

Multiply **every** term by a number that removes the denominators.

```example
x/2 + x/3 = 10. Find x.
1. 3x + 2x = 60 :: Multiply every term by 6.
2. 5x = 60 :: Combine like terms.
3. x = 12 :: Divide by 5.
```

```more
A **denominator** is the bottom number of a fraction. Both 2 and 3 divide into 6, so 6 clears both. Decimals work the same way. 0.25 has two digits after the point, so multiply every term by 100 to remove the decimals.
```

## Clear the decimals

```quiz
0.4x + 1.5 = 0.25x + 3. What is the value of x?
answer: 10
- 100 :: That is the number you multiplied by, not x.
> Multiply every term by 100: 40x + 150 = 25x + 300. Then 15x = 150, so x = 10.
~ type y=0.4x+1.5 :: Type each side as its own line.
~ type y=0.25x+3
~ zoom -2 20 -2 12
~ point (10, 5.5) :: Click the crossing: x = 10.
```

# Parentheses
Multiply every term inside. A minus flips signs.

## Open parentheses first

Multiply **every** term inside. A minus in front flips each sign.

```example
9 − 2(x − 4) = 3. Find x.
1. 9 − 2x + 8 = 3 :: −2 × −4 = +8.
2. 17 − 2x = 3 :: Combine 9 + 8.
3. −2x = −14 :: Subtract 17.
4. x = 7 :: Divide by −2.
```

```more
**Parentheses** group terms. The number outside multiplies each term inside: 2(x − 4) = 2x − 8. A minus sign in front acts like multiplying by −1, so every sign inside changes. Pay attention to −2 × −4: a negative times a negative is positive.
```

## Open them yourself

```quiz
7 − 2(x − 3) = 5. What is the value of x?
- −2 :: −2 × −3 is +6, not −6.
* 4
- −4 :: Sign slip: −8 ÷ −2 = 4, not −4.
> 7 − 2x + 6 = 5, so 13 − 2x = 5. Then −2x = −8 and x = 4.
~ type y=7-2(x-3) :: Type the left side as it is. Do not expand.
~ type y=5
~ point (4, 5) :: Click the crossing: x = 4.
```

# Word problems
Fee stands alone. Rate multiplies the letter.

## Fee plus rate

A one-time fee stands alone. A "per" amount multiplies the letter.

```example
A bike rental costs an $8 fee plus $5 per hour. Sam paid $33. How many hours?
1. 8 + 5h = 33 :: Fee + rate × hours = total.
2. 5h = 25 :: Subtract the fee.
3. h = 5 :: Divide by 5.
```

```more
The **fee** is charged once, so it does not change when the hours change. The **rate** is the price for each 1 hour, so it multiplies h. Total cost = fee + rate × hours.
```

## Build the equation

```quiz
A tutor charges a one-time $30 fee plus $15 per session. Ana paid $120 in total. How many sessions did she have?
answer: 6
- 8 :: You skipped the fee. Subtract 30 first.
- 10 :: The fee is inside the $120. Subtract it, do not add.
> 30 + 15s = 120, so 15s = 90 and s = 6.
~ type y=30+15x :: Cost after x sessions.
~ type y=120 :: The total paid.
~ zoom -1 10 -20 150
~ point (6, 120) :: Click the crossing: 6 sessions.
```

## What does the answer mean?

```quiz
The equation 40 + 30h = 190 gives a plumber's total charge for a job of h hours. Its solution is h = 5. What does h = 5 mean?
* The job took 5 hours when the total charge was $190.
- The plumber charges $5 for each hour. :: The rate is 30. Here 5 is the number of hours.
- The plumber's one-time fee is $5. :: The one-time fee is 40.
> The solution is the value of h that makes the total $190: 5 hours.
```

# Count the solutions
Same x-terms after simplifying: none or infinitely many.

## None, one, or all

After simplifying, x cancels? A false line like 4 = 7: **none**. A true line like 6 = 6: **infinitely many**.

```visual
linear-equations-one-var--solutions
```

```example
3(x + 2) = 3x + 6. How many solutions?
1. 3x + 6 = 3x + 6 :: Distribute the 3.
2. 6 = 6 :: Subtract 3x. This is always true.
3. Infinitely many :: Every x works.
```

```more
The **coefficient** of x is the number multiplying it: in 3x it is 3. When the coefficients on both sides are different, x does not cancel and there is exactly one solution. When x cancels, only the plain numbers are left: they are either equal (always true) or not equal (never true).
```

## How many solutions?

```quiz
4(x − 3) + x = 5x − 10. How many solutions?
- Exactly one :: Combine first: 4x + x = 5x on both sides.
- Infinitely many :: That needs equal numbers too. −12 ≠ −10.
* None
> The left side is 5x − 12. The x-terms cancel and −12 = −10 is false.
~ type y=4(x-3)+x :: Type each side as its own line.
~ type y=5x-10
~ zoom 0 4 -4 12
~ say :: Parallel lines never cross: no solution.
```

## Two unknown constants

```quiz
ax + 6 = 4x + b, where a and b are constants. The equation has infinitely many solutions. What is the value of a + b?
answer: 10
- 4 :: That is only a. Find b as well.
- 24 :: Add a and b. Do not multiply them.
> Both sides must be the same: a = 4 and b = 6. So a + b = 10.
~ slider a = 0 :: Make a slider for a.
~ slider b = 0
~ type y=ax+6 :: Each side as its own line.
~ type y=4x+b
~ slider a = 0 .. 4 :: The slopes match at a = 4.
~ slider b = 0 .. 6 :: The lines become one line at b = 6.
```

# Trap: they don't want x
Read the last line. Solve for that block.

## Solve for the block

Asked for x − 4? Keep it whole and solve for it.

```example
3(x − 4) + 2 = 20. Find x − 4.
1. 3(x − 4) = 18 :: Subtract 2.
2. x − 4 = 6 :: Divide by 3. Stop here.
```

```more
The question asks for the value of a whole group, x − 4. You do not need x alone. Treat the group as one unknown. You can call it u: 3u + 2 = 20, so u = 6. Solving for x first (x = 10) only adds work and a chance to make a mistake.
```

## Answer the question

```quiz
5(x + 2) − 3 = 2(x + 2) + 18
In the given equation, x is a constant. According to this equation, what is the value of x + 2?
answer: 7
- 5 :: That is x. The question asks for x + 2.
- 21 :: That is 3(x + 2). Divide it by 3.
> Call x + 2 "u": 5u − 3 = 2u + 18, so 3u = 21 and u = 7.
~ type y=5(x+2)-3 :: Type each side as it is.
~ type y=2(x+2)+18
~ zoom -2 10 -5 50
~ point (5, 32) :: Crossing at x = 5. So x + 2 = 7.
```
