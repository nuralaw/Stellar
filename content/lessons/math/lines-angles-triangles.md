# Parallel lines
Eight angles, only two sizes. They add to 180°.

## Equal, or add to 180°

A line crossing two parallel lines (a **transversal**) makes eight angles but only **two sizes**. One of each adds to **180°**.

```visual
lines-angles-triangles--transversal
```

```example
A line crosses two parallel lines. One angle is 70°. Find the other seven.
1. Vertical (opposite) angle: 70° :: Across the crossing point: equal.
2. Next to it: 180° − 70° = 110° :: A straight line is 180°.
3. Other crossing: the same four angles :: Parallel lines repeat them.
4. Four angles are 70°. Four are 110°.
```

```more
**Parallel** lines never meet. The arrow marks on a figure show lines are parallel. **Vertical angles** sit opposite each other where two lines cross, and they are equal. Two angles next to each other on a straight line add to 180°.
```

## Find the other size

```quiz
A line crosses two parallel lines. One of the angles measures 125°. What is the measure, in degrees, of each acute angle?
answer: 55
- 125 :: That is the obtuse size. Acute means less than 90°.
- 35 :: You subtracted 90. The two sizes add to 180.
> Only two sizes, and they add to 180°: 125° and 180° − 125° = 55°.
```

# Triangle angles
Angles add to 180°. Equal sides face equal angles.

## Isosceles triangles

A triangle's angles add to **180°**. **Isosceles**: two equal sides, so two equal angles. △PQR = triangle PQR. ∠P = angle P.

```visual
lines-angles-triangles--isosceles
```

```example
In △PQR, PQ = PR and ∠Q is 65°. Find ∠P.
1. ∠R = ∠Q = 65° :: Equal sides, so equal angles at R and Q.
2. ∠P = 180° − 65° − 65° :: The three angles add to 180°.
3. ∠P = 50°
```

```more
**△PQR** means triangle PQR. **∠P** means angle P. An **isosceles** triangle has two equal sides, and tick marks on a figure show which sides are equal. Here PQ and PR have ticks, so the angles at Q and R are equal.
```

## Two equal angles

```quiz
In △ABC, AB = AC and ∠A measures 40°. What is the measure, in degrees, of ∠B?
answer: 70
- 40 :: Angle A sits between the equal sides. B equals C.
- 140 :: That is B and C together. Divide it by 2.
> B = C, and B + C = 180° − 40° = 140°. So B = 70°.
```

## Angles with x

```quiz
A triangle's angles are x°, (x + 10)° and (2x − 30)°. What is the largest angle?
- 50° :: That is x, the smallest angle. Find all three.
* 70°
- 60° :: That is x + 10. The largest is 2x − 30.
> x + (x + 10) + (2x − 30) = 180, so x = 50. Angles: 50°, 60°, 70°.
~ type y=x+(x+10)+(2x-30) :: Type the sum of the three angles.
~ type y=180 :: The sum must be 180.
~ zoom 0 100 0 250
~ point (50, 180) :: Click the crossing: x = 50.
~ say :: Largest: 2 × 50 − 30 = 70°.
```

# Exterior angles
Exterior = the two far angles. Polygons: (n − 2) × 180°.

## Exterior angle

Extend one side. The **exterior angle** equals the sum of the two angles that do not touch it.

```visual
lines-angles-triangles--exterior
```

```example
In △ABC, ∠A = 50° and ∠B = 60°. Side BC is extended to D. Find the exterior angle ∠ACD.
1. ∠ACD = ∠A + ∠B :: The two angles not touching it.
2. 50° + 60° = 110°
```

```more
Check it another way: ∠C inside the triangle is 180° − 50° − 60° = 70°. The exterior angle and ∠C make a straight line, so ∠ACD = 180° − 70° = 110°. Both ways give the same answer.
```

## Polygon angles

A polygon with n sides has interior angles that add to (n − 2) × 180°.

```quiz
A regular hexagon has six equal angles. What is the measure, in degrees, of each angle?
answer: 120
- 720 :: That is the sum of all six angles. Divide it by 6.
- 60 :: That is 360 ÷ 6. The angle sum is (6 − 2) × 180.
> (6 − 2) × 180 = 720. Six equal angles: 720 ÷ 6 = 120.
```

# Similar triangles
Match the letters. Multiply every side by one number.

## One ratio

**Similar** (~) triangles have equal angles. Every side is multiplied by one number. Letter order shows what matches.

```visual
lines-angles-triangles--similar
```

```example
△PQR ~ △XYZ. PQ = 3, PR = 7 and XY = 12. Find XZ.
1. XY matches PQ: 12 ÷ 3 = 4 :: Same letter positions match.
2. XZ matches PR :: First and third letters.
3. XZ = 7 × 4 = 28
```

```more
The sign ~ means "is similar to". Scaling changes lengths but never angles: ∠P = ∠X, ∠Q = ∠Y and ∠R = ∠Z. In the picture, equal angles have the same arc marks.
```

## Match the sides

```quiz
△ABC ~ △DEF. AB = 4, BC = 6, AC = 8 and DE = 10. What is the length of DF?
answer: 20
- 15 :: That is EF. DF matches AC: first and third letters.
- 14 :: You added 6. Similar means multiply, not add.
> DE matches AB: 10 ÷ 4 = 2.5. DF matches AC: 8 × 2.5 = 20.
```

# Line inside a triangle
A parallel line cuts off a smaller copy.

## Nested triangles

A line DE parallel to side BC cuts off a smaller triangle ADE. It is similar to the whole triangle ABC.

```visual
lines-angles-triangles--nested
```

```example
In △ABC, D is on AB and E is on AC, with DE ∥ BC. AD = 4, DB = 2 and DE = 6. Find BC.
1. AB = AD + DB = 6 :: Use the whole side.
2. AD/AB = DE/BC, so 4/6 = 6/BC :: △ADE ~ △ABC.
3. BC = 9 :: 4 × BC = 36.
```

```more
**DE ∥ BC** means DE is parallel to BC. Then the angles at D and B are equal, and both triangles share angle A, so they are similar. Compare the small triangle to the **whole** triangle: AD/AB, not AD/DB.
```

## Use the whole side

```quiz
In △ABC, point D is on AB and point E is on AC, with DE ∥ BC. AD = 3, DB = 6 and DE = 5. What is the length of BC?
answer: 15
- 10 :: You used AD/DB. Compare with the whole side AB = 9.
- 7.5 :: You used DB in the ratio. Use the whole side AB.
> AB = 3 + 6 = 9. AD/AB = DE/BC gives 3/9 = 5/BC, so BC = 15.
```

## Fraction of a side

AD is 1/3 of AB means AD : DB = 1 : 2, and AD : AB = 1 : 3.

```quiz
In △ABC, point D is on AB and point E is on AC, with DE ∥ BC. AD is 1/3 of AB, and DE = 5. What is the length of BC?
answer: 15
- 10 :: You used AD : DB = 1 : 2. Use AD : AB = 1 : 3.
- 5 :: That is DE. BC is longer: BC is 3 times DE.
> AD : AB = 1 : 3, so DE : BC = 1 : 3. BC = 3 × 5 = 15.
```

```more
Turning a fraction of a side into a ratio: if PM is 2/5 of PQ, the rest MQ is 3/5 of PQ. So PM : MQ = 2 : 3. The two parts always add up to the whole: 2/5 + 3/5 = 1.
```

# Prove similar
Two equal angle pairs prove similar. Then match sides.

## Two equal angles

Two pairs of equal angles prove **similar**. **Congruent** means similar and the same size.

```visual
lines-angles-triangles--aa
```

```example
In △ABC, D is on AB and E is on AC, with ∠ADE = ∠ACB. AD = 4, AC = 8 and AE = 3. Find AB.
1. ∠A is shared, ∠ADE = ∠ACB :: Two equal angle pairs: similar.
2. △ADE ~ △ACB :: Letters in order: A–A, D–C, E–B.
3. AD/AC = AE/AB, so 4/8 = 3/AB :: Cross-multiply: 4 × AB = 24.
4. AB = 6
```

```more
Angle A is inside both triangles, so it is one equal pair. The given ∠ADE = ∠ACB is the second pair. Write the similar triangles with matching letters in order: A with A, D with C, E with B. Then match sides: AD with AC, and AE with AB. **Congruent** also needs equal sizes.
```

## Prove congruent

```quiz
In △ABC and △DEF, ∠A = ∠D and ∠B = ∠E. Which extra fact proves the triangles congruent?
- ∠C = ∠F :: That is already true. Equal angles prove only similar.
* AB = DE
- AB = 2 × DE :: Then ABC is twice as big: similar, not congruent.
> Equal angles fix the shape. A pair of equal matching sides fixes the size.
```

# Trap: equal or 180°?
Acute plus obtuse is 180°. Answer what is asked.

## Add, don't equate

An acute and an obtuse angle are the two sizes: they add to 180°. Then answer what is asked, not x.

```visual
lines-angles-triangles--trap
```

```example
A line crosses two parallel lines. An acute angle is (x + 10)° and an obtuse angle is (4x − 30)°. Find the acute angle.
1. (x + 10) + (4x − 30) = 180 :: Different sizes: add to 180°.
2. 5x − 20 = 180, so x = 40
3. Acute angle: 40 + 10 = 50° :: The question asks for the angle.
```

```more
Angles of the **same size** are equal: set them equal. Angles of **different sizes** (one acute, one obtuse) add to 180°. Look at the picture: if one angle looks small and the other looks big, add them.
```

## Spot the trap

```quiz
A line crosses two parallel lines. An acute angle is (x + 20)° and an obtuse angle is (3x)°. What is the obtuse angle?
- 30° :: Trap: you set them equal. Acute + obtuse = 180°.
- 40° :: That is x. The obtuse angle is 3x.
* 120°
- 60° :: That is the acute angle, x + 20.
> (x + 20) + 3x = 180, so x = 40. The obtuse angle is 3 × 40 = 120°.
~ type y=(x+20)+3x :: Type acute + obtuse.
~ type y=180 :: Together they make 180.
~ zoom 0 80 0 240
~ point (40, 180) :: Click the crossing: x = 40.
~ say :: Obtuse: 3 × 40 = 120°.
```

## Larger angle

```quiz
Lines m and n are parallel and are cut by transversal t. One angle formed measures (2x + 10)°. Another angle, next to it on a straight line, measures (4x − 10)°. What is the measure, in degrees, of the larger of the two angles?
answer: 110
- 70 :: That is the smaller angle, 2x + 10. Find the larger one.
- 30 :: That is x. Put x back into 4x − 10.
> The two angles add to 180°: 6x = 180, so x = 30. The larger angle is 4(30) − 10 = 110°.
```
