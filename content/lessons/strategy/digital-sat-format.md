## Module 1 decides module 2

Each section has two timed modules. **How you do on module 1 sets module 2: harder or easier.**

```example
You do well on Reading and Writing module 1. What comes next?
1. Module 1: 27 questions, 32 minutes :: Easy, medium and hard, mixed.
2. Did well → harder module 2 :: The test adapts once per section.
3. Harder module 2 → scores up to 800 :: The easier one caps your score.
4. So: do your most careful work in module 1
```

## Don't miss on purpose

```quiz
A classmate plans to miss a few module 1 questions on purpose, to get the easier module 2. What happens to her score?
* It drops
- It rises: she gets more right in module 2 :: The easier module 2 caps how high she can score.
- Nothing changes :: Module 1 misses cost points and the harder path.
> The missed points are gone, and the easier module 2 limits her top score.
```

## A finished module locks

Each module has its own timer. At 0:00 it closes for good.

```quiz
The module 1 timer hits 0:00. Questions 25 to 27 are still blank. What happens to them?
* They stay blank and score zero
- You can answer them after module 2 :: A closed module never reopens.
- You get a short grace period :: No extra time: 0:00 ends the module.
> The app moves you on by itself. Enter a guess for every question before time runs out.
```

## Where the hard ones sit

Math runs easier to harder. Reading and Writing goes type by type, and each new type starts easier again.

```quiz
In Reading and Writing, you're stuck on a very hard vocabulary question. The next question starts a new type: text purpose. What should you expect from it?
* Probably easier
- Even harder :: That's Math. Here each new type restarts easier.
- About the same :: Difficulty climbs inside a type, then resets.
> The hardest question of one type sits right before the easiest of the next. Guess, flag it, move on.
```

## Typed answers: no mixed numbers

Some Math answers are typed: up to 5 characters, 6 with a minus sign. No mixed numbers, no symbols.

```quiz
Your answer is 4¼. Which entry earns credit?
* `17/4`
- `4 1/4` :: Mixed numbers aren't accepted.
- `41/4` :: That reads as 41 ÷ 4 = 10.25.
> 4¼ = 16/4 + 1/4 = 17/4. The decimal `4.25` works too.
```

## Long decimals fill the box

A decimal that doesn't fit must use every space, rounded or cut off. Shorter is marked wrong.

```quiz
Your answer is −7/9 = −0.7777… Which decimal entry earns credit?
* `-.7778`
- `-0.78` :: Too short. Use all 6 characters.
- `-0.7778` :: That's 7 characters. A negative answer gets 6.
> `-.7778`, `-.7777`, `-0.777` and `-0.778` all count. Easiest: type the fraction `-7/9`.
```

## Trap: leaving blanks

A wrong answer and a blank both score zero. Nothing is subtracted.

```quiz
Ten seconds left. One question is unanswered and you have no idea. What's the best move?
* Click any choice
- Leave it blank: a wrong answer costs points :: Trap: no penalty exists. A blank is a sure zero.
- Recheck an earlier answer instead :: That leaves a sure zero on the blank one.
> A guess can score. A blank can't.
```

## Recap

- Module 1 sets module 2: be most careful there.
- Reading and Writing: 27 questions in 32 minutes per module. Math: 22 in 35.
- Never leave a blank.
