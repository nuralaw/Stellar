# linear-inequalities--budget

**Shows:** a two-variable budget inequality: each number has a job (price, count, limit), and a test point is just put in and compared.

**Storyboard:**
1. The inequality `\(7s + 4m \le 80\)` appears. Under it three tags light up in turn: `7` = "price of one sandwich", `s` = "how many sandwiches", `80` = "limit".
2. A grid (s on the horizontal axis, m vertical) draws the boundary line `\(7s + 4m = 80\)`; the region below is lightly shaded.
3. The test point (6, 9) lands on the grid; a pop-up computes `\(42 + 36 = 78\)`, `\(78 \le 80\)`, a green tick.
4. The point (8, 7) lands outside; `\(56 + 28 = 84\)`, `\(84 \le 80\)` is false, a red cross.

**Labels & formulas:** `\(7s + 4m \le 80\)`, `\(42 + 36 = 78\)`, `\(56 + 28 = 84\)`, point labels `\((6, 9)\)`, `\((8, 7)\)`.

**Stress:** the tags on the inequality parts (price / count / limit) are the main teaching; keep the grid secondary and light. Green for the allowed point, red for the other.
