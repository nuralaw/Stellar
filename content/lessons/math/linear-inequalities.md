# Flip the sign
Divide by a negative, flip the sign.

## Divide by a negative? Flip

Solve it like an equation. One extra rule: **multiply or divide by a negative → flip the sign.**

```visual
linear-inequalities--mirror
```

```example
Solve −2x + 3 > 11.
1. −2x > 8 :: Subtract 3. No flip.
2. x < −4 :: Divide by −2: > flips to <.
```

```more
An **inequality** compares two values with <, >, ≤ or ≥. Multiplying by −1 mirrors the number line, so the order turns around: 2 < 3 becomes −2 > −3. Only multiplying or dividing by a negative flips the sign. Adding or subtracting never flips it. Dividing by a positive never flips it, even when the other side is negative.
```

## Flip it yourself

```quiz
Solve 5 − 4x ≤ 17.
- x ≤ −3 :: You divided by −4 but did not flip the sign.
- x ≥ 3 :: 12 ÷ (−4) = −3, not 3.
* x ≥ −3
> −4x ≤ 12. Divide by −4 and flip: x ≥ −3. Test 0: 5 ≤ 17 is true, and 0 ≥ −3.
~ type 5-4x\le 17 :: Type it as it is.
~ zoom -10 10 -5 5
~ point (-3, 0) :: The shading starts at −3 and goes right: x ≥ −3.
```

## Flip only for the divisor

```quiz
Solve 3x + 10 < 4.
- x > −2 :: Trap: you divided by +3. A positive never flips.
- x < 2 :: 4 − 10 = −6, not 6.
* x < −2
> 3x < −6. Divide by 3, a positive: no flip. x < −2. Test −3: 1 < 4 is true.
~ type 3x+10<4 :: Type it as it is.
~ zoom -10 10 -5 5
~ point (-2, 0) :: The shading starts at −2 and goes left: x < −2.
```

# Words to symbols
At least is ≥. At most is ≤.

## Turn words into symbols

**At least** means ≥. **At most** and **no more than** mean ≤.

```example
A van carries at most 900 kg. The driver weighs 80 kg and each box 20 kg. Write an inequality for b boxes.
1. 80 + 20b :: The driver counts once. 20 kg per box.
2. 80 + 20b ≤ 900 :: "At most" means ≤.
```

```more
**At least 150** means 150 or more: a floor. **At most 900** means 900 or less: a ceiling. Also "minimum" means at least and "maximum" means at most. The fixed amount (80) stands alone. The amount per item (20) multiplies the letter.
```

## Write it yourself

```quiz
Mia has $30 and saves $12 each week. She needs at least $150. Which inequality gives the number of weeks w she must save?
- 30 + 12w ≤ 150 :: "At least" is a floor, so use ≥.
- 12 + 30w ≥ 150 :: $12 comes every week, so 12 multiplies w.
- 30 + 12w > 150 :: Exactly $150 is enough, so 150 must count.
* 30 + 12w ≥ 150
> She starts with 30 and adds 12 per week: 30 + 12w. "At least 150" means ≥ 150.
```

# Two variables in a story
Add both costs. Then test a point.

## Test the point

Two items: add both costs on the left. Test a point by putting in x and y.

```example
Notebooks cost $3 and pens $2. A student spends at most $60: 3x + 2y ≤ 60. Is (10, 15) allowed?
1. 3(10) + 2(15) :: Put in x = 10 and y = 15.
2. 30 + 30 = 60 :: Add.
3. 60 ≤ 60 is true :: Yes. Exactly 60 counts for ≤.
```

```more
A **solution** of an inequality in two variables is a point (x, y) that makes it true. Put x and y into the left side, work out the number, and compare it with the right side. The words "at most" allow an equal total, so 60 is allowed.
```

## Write the inequality

```quiz
A club has $90 to spend on x posters at $4 each and y banners at $9 each. Which inequality represents this situation?
- 4x + 9y ≥ 90 :: A budget is a limit. The total cannot be more than 90.
- 9x + 4y ≤ 90 :: The prices are swapped. A poster costs $4.
* 4x + 9y ≤ 90
> Posters cost 4x and banners cost 9y. The total cannot go above $90.
```

## Use the inequality

```quiz
A club has $90 to spend on x posters at $4 each and y banners at $9 each, so 4x + 9y ≤ 90. If the club buys 6 posters, what is the greatest number of banners it can buy?
answer: 7
- 8 :: 8 banners plus the posters cost $96. Too much.
- 66 :: That is the money left. Divide it by 9.
> 4(6) + 9y ≤ 90, so 9y ≤ 66 and y ≤ 7.33. Banners are whole items: round down to 7.
```

# What the numbers mean
Each number in an inequality has a job.

## Name each part

A number times a letter is a price (or rate). The number alone is the limit.

```example
A caterer spends at most $200 on x trays at $15 each and y drinks at $8 each: 15x + 8y ≤ 200. What do 15x, 8y and 200 mean?
1. 15x :: Money spent on trays: $15 times x.
2. 8y :: Money spent on drinks: $8 times y.
3. 200 :: The most the caterer can spend.
```

```more
In 15x + 8y ≤ 200, the number in front of a letter tells the **price of one item**. The letter tells how many items. The number on the right is the **limit**, here the budget. The sign ≤ means the total can be equal to the limit or less.
```

## Meaning of 15

```quiz
A school club sells x T-shirts and y caps to raise at least $200. The inequality 15x + 8y ≥ 200 represents the goal. What does the 15 represent?
* The money the club earns from each T-shirt, in dollars.
- The number of T-shirts the club sells. :: The number of T-shirts is x. 15 multiplies it.
- The amount the club hopes to raise. :: That is the 200 on the right.
> 15 multiplies x, the number of T-shirts, so it is the dollars earned per T-shirt.
```

# Read a shaded graph
Dashed or solid. Above or below.

## Solid, dashed, above, below

Dashed line: < or >, not included. Solid line: ≤ or ≥. Shade above for y >, below for y <.

```visual
linear-inequalities--shading
```

```desmos
y ≥ x − 1 and y < −x + 5. Is (2, 2) a solution?
type y\ge x-1 :: Type each inequality on its own line.
type y<-x+5
point (2, 2) :: Inside both shadings: it is a solution.
```

```more
To graph an inequality, first draw its line as if it were an equation. Then shade the side where the inequality is true. y > mx + b is the region above the line. y < mx + b is the region below. For a system, the solutions are the points where all the shadings overlap. To be sure, test a point.
```

## Match the graph

```quiz
A graph in the xy-plane shows a solid line through (0, 3) and (3, 0). The region below the line is shaded. Which inequality represents the graph?
- y < −x + 3 :: A solid line means the line counts: use ≤.
- y ≥ −x + 3 :: Below the line means y is smaller: use ≤.
* y ≤ −x + 3
> The slope is (0 − 3) ÷ (3 − 0) = −1, so the line is y = −x + 3. Solid and below: ≤.
~ type y\le -x+3 :: Type the choice.
~ point (0, 3) :: The line passes through (0, 3).
~ point (3, 0) :: And through (3, 0). Shading is below.
```

## Test it yourself

```quiz
y > 3x − 2
x + y ≤ 6
Which point (x, y) is a solution to the system?
- (2, 4) :: 4 > 4 is false. On the line does not count for >.
* (1, 4)
- (1, 7) :: Passes the first, but 1 + 7 = 8 is over 6.
- (3, 1) :: Passes the second, but 1 > 7 is false.
> (1, 4): 4 > 3(1) − 2 = 1 is true, and 1 + 4 = 5 ≤ 6 is true.
~ type y>3x-2 :: Type both inequalities as they are.
~ type x+y\le 6
~ point (1, 4) :: Only (1, 4) sits where both shadings overlap.
```

# Trap: round the right way
Limits round down. Goals round up.

## Whole numbers only

Under a limit, round **down**. To reach a goal, round **up**. Never to the nearest.

```example
Tickets cost $7 each. A club needs at least $100. What is the least number of tickets it must sell?
1. 7t ≥ 100 :: "At least" means ≥.
2. t ≥ 100/7 ≈ 14.29 :: Divide by 7.
3. 15 tickets :: A goal: round up. 14 gives only $98.
```

```more
Tickets come in whole numbers, so 14.29 tickets is not possible. 14 tickets give 14 × 7 = $98, which is less than $100. The smallest whole number that works is 15. A limit is different: 8.67 games means at most 8 games, because 9 games would go over the limit.
```

## Round it yourself

```quiz
A bowling alley charges a $4 shoe rental fee plus $3 for each game played. Dana has $30 to spend. If she plays g games, what is the greatest number of games she can play?
answer: 8
- 9 :: 9 games cost $31, over budget. Round down.
- 10 :: You left out the $4 for shoes.
> 4 + 3g ≤ 30, so g ≤ 8.67. She cannot go over $30: round down to 8.
~ type y=4+3x :: The cost of x games.
~ type y=30 :: Her budget.
~ zoom 0 12 0 40
~ point (8, 28) :: 8 games cost $28. 9 games cost $31: over the line.
```
