# linear-functions--input-output

**Shows:** in \(f(a) = b\) the number inside the brackets is the input and the number after the equals sign is the output, and it is the point \((a, b)\) on the graph.

**Storyboard:**
1. A function machine box labelled \(f(x) = 4x - 5\). An input chip "3" slides in on the left.
2. Inside the box: \(4(3) - 5\); an output chip "7" slides out on the right. Caption \(f(3) = 7\).
3. The same pair becomes a point: a grid appears and \((3, 7)\) lights up on the line. The "3" is labelled input (\(x\)-axis), "7" output (\(y\)-axis).
4. Reverse: an output chip "19" enters from the right side with a question mark on the input side: \(f(k) = 19\) becomes \(4k - 5 = 19\); \(k = 6\) is solved and \((6, 19)\) lights up.

**Labels & formulas:** "input", "output", \(f(x) = 4x - 5\), \(f(3) = 7\), \(f(k) = 19\), \(4k - 5 = 19\), \(k = 6\).

**Stress:** input chips in one colour, output chips in a second colour, both consistent across frames. The unknown \(k\) gets a pulsing question mark. Phone-readable: chips ≥ 24 units wide.
