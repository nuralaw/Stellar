# linear-equations-one-var--rearrange

**Shows:** solving for a letter uses the same balance moves, undoing operations in reverse order, with the other letters treated like numbers.

**Storyboard:**
1. \(F = \frac{9}{5}C + 32\) appears; \(C\) is circled with a target icon, \(F\) is dimmed as "just a number".
2. Layer peel: a nesting bracket diagram shows \(C\) wrapped first by \(\times\frac{9}{5}\), then by \(+32\).
3. Undo from the outside: "\(-32\) on both sides" gives \(F - 32 = \frac{9}{5}C\); the whole left side stays together in a bracket.
4. "\(\times \frac{5}{9}\) on both sides" gives \(C = \frac{5}{9}(F - 32)\). The bracket around \(F - 32\) is highlighted.
5. A faded wrong version \(C = \frac{5}{9}F - 32\) slides in with a red cross, then leaves.

**Labels & formulas:** "treat \(F\) like a number", "undo in reverse order", \(F - 32 = \frac{9}{5}C\), \(C = \frac{5}{9}(F - 32)\).

**Stress:** the target letter in accent colour; the bracket around \(F - 32\) pulses once (multiply the WHOLE side). Red only for the rejected \(\frac{5}{9}F - 32\).
