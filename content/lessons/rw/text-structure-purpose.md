# Main purpose
Label each sentence's job. The point often follows a turn.

## Name the text's job

Ask what the text **does**, not what it says. A **turn** is a word like *but* or *in fact* that changes direction.

```example
Many people think bats are blind. In fact, most bats see well, and fruit bats rely on sharp eyesight to find ripe fruit.
Which choice best states the main purpose of the text?
1. Sentence 1: a common belief :: Label the job, not the topic.
2. Sentence 2: *In fact* + evidence against it :: Spot the turn.
3. Answer: To correct a common belief about bats :: Not "to explain how bats see".
```

```more
The **purpose** is the reason the author wrote the text: to correct, to explain, to compare, to argue. Choices start with "To" plus a verb. Pick the verb that describes the whole text, not only one sentence.
```

## Find the turn

```quiz
Historians long treated one town's 1890s cookbooks as plain recipe collections. But Dana Okoro found margin notes on prices and shortages. The cookbooks, she argues, record the town's economic life.
Which choice best states the main purpose of the text?
- To describe the recipes in old cookbooks :: That is the old view, before *But*.
- To explain why prices rose in the 1890s :: Prices are one detail. No rise is explained.
* To present a historian's argument that the cookbooks record more than recipes
> Old view → *But* → her claim. The purpose is the claim after the turn.
```

# One sentence's job
Ask what the sentence does for its neighbors.

## Read the neighbors

One sentence is underlined (**bold** here). Read the sentences before and after it.

```example
Coral reefs cover less than 1% of the ocean floor. **Yet about a quarter of all sea species live on them.** Biologists therefore call reefs the rainforests of the sea.
Which choice best describes the function of the underlined sentence in the text as a whole?
1. Before: reefs are tiny :: Label the neighbor before.
2. Bold: *Yet* + a huge share of species :: A contrast.
3. After: *therefore* a nickname :: The bold fact is the reason.
4. Answer: It gives a contrasting fact that explains the nickname :: The job, not the topic.
```

```more
The underlined part can be one sentence or only a phrase. **Function** means the job it does for the whole text. Ask two questions: what does it do to the sentence before it, and what does the sentence after it do with it?
```

## Name the bold sentence

```quiz
City sparrows sing higher than country sparrows, one study found, probably to be heard over traffic. **But the study covered only two cities.** Whether sparrows elsewhere do the same is unknown.
Which choice best describes the function of the underlined sentence in the text as a whole?
* It points out a limit of the study.
- It gives evidence that higher songs beat traffic noise. :: It does not support the finding. It limits it.
- It contradicts the study's finding. :: Nothing is contradicted. The finding stands for those two cities.
> Finding → limit (bold) → so the wider question stays open.
```

# Job verbs
Learn the verbs that choices use.

## The job verbs

Choices name jobs with verbs. **Concedes** means admits a point to the other side. Learn the list in the scale below.

```visual
text-structure-purpose--verbs
```

```example
Wind farms are often criticized as noisy. **Admittedly, a turbine close to a house can hum.** But at 500 meters, the sound is quieter than a refrigerator.
Which choice best describes the function of the underlined sentence in the text as a whole?
Choices: It concedes a point to critics. / It refutes the claim that wind farms are noisy. / It illustrates how quiet turbines are.
1. Sentence 1: critics say wind farms are noisy :: The claim being tested.
2. Bold: *Admittedly* + a small agreement :: It gives critics a point.
3. After: *But* + quiet at 500 m :: The author pushes back.
4. Answer: (A) concedes :: It admits a point.
```

```more
**Sets up** = introduces what comes next. **Elaborates** = adds detail. **Illustrates** = gives an example. **Supports** = gives evidence. **Concedes** = admits a point. **Qualifies** = limits a claim. **Undermines** = weakens it. **Refutes** = proves it wrong.
```

## Name the verb

```quiz
Octopuses are surprisingly good at solving problems. **In one lab, an octopus opened a screw-top jar of crabs in under a minute.** Researchers say such results suggest that octopuses can learn by trial and error.
Which choice best describes the function of the underlined sentence in the text as a whole?
- It concedes that octopuses are poor learners. :: Nothing in the sentence admits a weakness.
* It illustrates a claim about octopus intelligence with an example.
- It undermines the idea that octopuses can learn. :: It supports that idea. It does not weaken it.
> Sentence 1 makes a claim. The bold sentence gives one example of it.
```

# Verb strength
Qualify or refute? Go only as far as the text.

## Match the verb

*Refute* = prove wrong. *Qualify* = true, but only partly.

```example
Cats are said to always land on their feet. They usually do, twisting in midair. But in very short falls, they lack the time to turn.
Which choice best states the main purpose of the text?
1. Sentence 1: a common claim :: Find the claim.
2. *Usually do* … *But* in short falls :: Mostly true, with an exception.
3. Answer: To qualify a common claim about cats :: Not *refute*: the claim mostly holds.
```

```more
A verb must match the text's strength. If the text says "usually, but not always", the claim is only limited, so the verb is *qualifies*. *Refutes* is for a text that says the claim is simply wrong. Choose the verb whose strength matches the text.
```

## Refute or qualify?

```quiz
Edison is often credited with inventing the light bulb. In fact, over twenty inventors built bulbs before him. Still, his long-lasting bulb made electric light practical, so his fame is partly deserved.
Which choice best states the main purpose of the text?
- To refute the idea that Edison deserves his fame :: Too strong. The text says "partly deserved."
* To qualify a common claim about Edison
- To explain how Edison's bulb worked :: The bulb is mentioned. Nothing explains how it works.
> The claim is narrowed, not thrown out: he was not first, but he made electric light practical.
```

# Text structure
List the jobs in order: first this, then that.

## Map the order

**Structure** = the jobs in order. Every part of a choice must be true, in the text's order.

```visual
text-structure-purpose--structure
```

```example
The old squire had always laughed at ghosts. Yet when the clock in the empty hall struck thirteen, he lit every candle in the house.
Which choice best describes the overall structure of the text?
Choices: It states a belief, then shows behavior that contradicts it. / It describes a house, then explains why it is empty.
1. Sentence 1: he laughs at ghosts :: Job 1: a belief.
2. Sentence 2: *Yet* + he lights every candle :: Job 2: behavior against it.
3. Answer: (A) belief, then the opposite :: Both parts true, in order.
```

```more
Number the jobs: first, then, finally. Then read each choice one part at a time. Choice B fails twice: the text never describes a house, and it never says why the hall is empty. One false part is enough to cross a choice out.
```

## Test every part

```quiz
Every summer, Marta counted the days until she could leave her grandmother's quiet farm. Now, years later, in her noisy city apartment, she missed the creak of the porch swing.
Which choice best describes the overall structure of the text?
- It shows a character missing a place, then explains why she left it. :: Wrong order, and no reason for leaving is given.
* It recalls a character's past feeling about a place, then shows that the feeling has changed.
- It describes a farm, then explains why it was sold. :: No sale is mentioned. One false part makes the whole choice wrong.
> Then: eager to leave. Now: missing it. Both parts true, in order.
```

# Trap: true, wrong job
A true detail can still miss the whole job.

## True but too small

A choice can repeat a true detail and still miss the job. The purpose covers the whole text.

```example
Saffron is known as an expensive spice. But what makes it costly is the harvest: each crocus flower gives only three red threads, and every one is picked by hand.
Which choice best states the main purpose of the text?
Choices: To state that saffron is a spice. / To explain why saffron is expensive.
1. Trap: "saffron is a spice" :: True, but only sentence 1.
2. *But* + the harvest is the reason :: The point follows the turn.
3. Answer: (B) :: It covers the whole text.
```

```more
A trap choice copies a true detail from one sentence. Ask: does it cover the whole text, including the part after the turn? If it only matches the first sentence, it names a detail, not the purpose.
```

## Spot the trap

```quiz
Many recipes say dough must rise somewhere warm. A test kitchen found that dough left overnight in a refrigerator rose just as well. The bakers note, though, that they tested only one kind of bread.
Which choice best states the main purpose of the text?
- To report that refrigerated dough rose as well as warm dough :: Trap: true, but it is only the middle sentence.
- To prove that recipes give bad advice :: Too strong. One test of one bread proves nothing.
* To present a finding that challenges common advice, and its limit
> Advice → finding against it → limit. The purpose covers all three.
```
