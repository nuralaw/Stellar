# linear-functions--translate

**Shows:** adding to the output moves a line up or down, replacing \(x\) by \(x - h\) moves it right, and the slope never changes.

**Storyboard:**
1. Grid with the line \(f(x) = 2x + 5\) in the accent colour; its \(y\)-intercept dot at (0, 5).
2. Copy of the line slides down 3: label \(f(x) - 3\), new equation \(2x + 2\), dot at (0, 2). A vertical arrow "down 3".
3. Original line again; a copy slides right 4: label \(f(x - 4)\), new equation \(2x - 3\), dot at (0, \(-3\)). A horizontal arrow "right 4".
4. Both copies show the same slope triangle (run 1, rise 2). A small note: "slope unchanged".

**Labels & formulas:** \(f(x) = 2x + 5\), \(f(x) - 3 = 2x + 2\), \(f(x - 4) = 2x - 3\), "down 3", "right 4", "same slope".

**Stress:** original line neutral, moving copy in the accent; intercept dots follow the copy. Arrows are short and thick. One shift per beat so nothing overlaps; keep labels near the line ends, ≥ 11 units.
