## Same move, both sides

Do the **same thing to both sides** until x stands alone.

```example
3x + 2 = x + 8. Find x.
1. 2x + 2 = 8 :: Subtract x from both sides.
2. 2x = 6 :: Subtract 2 from both sides.
3. x = 3 :: Divide both sides by 2.
```

## Solve it yourself

```quiz
5x − 4 = 2x + 11. What is the value of x?
* 5
- 15 :: That's 3x. Divide by 3.
- 7/3 :: Add 4 to both sides: 11 + 4 = 15, not 7.
> Subtract 2x: 3x − 4 = 11. Add 4: 3x = 15. Divide by 3: x = 5.
```

## Open parentheses first

Multiply every term inside. A minus in front flips each sign.

```quiz
7 − 2(x − 3) = 5. What is the value of x?
* 4
- −2 :: −2 × −3 is +6, not −6.
- −4 :: Sign slip: −8 ÷ −2 = 4, not −4.
> 7 − 2x + 6 = 5, so 13 − 2x = 5. Then −2x = −8 and x = 4.
```

## Stories: fee plus rate

A one-time fee stands alone. A "per" amount multiplies the letter.

```quiz
A tutor charges a one-time $30 fee plus $15 per session. Ana paid $120 in total. How many sessions did she have?
* 6
- 8 :: You skipped the fee. Subtract 30 first.
- 10 :: The fee is inside the $120. Subtract it, don't add.
> 30 + 15s = 120, so 15s = 90 and s = 6.
```

## Count the solutions

Same x-coefficient on both sides? Different plain numbers: no solution. Same numbers: infinitely many. Otherwise: exactly one.

```quiz
4(x − 3) + x = 5x − 10. How many solutions?
- Exactly one :: Combine first: 4x + x = 5x on both sides.
* None
- Infinitely many :: That needs equal numbers too. −12 ≠ −10.
> The left side is 5x − 12. The x-terms cancel and −12 = −10 is false.
```

## Trap: they don't want x

Read the last line. Asked for x + 2? Solve for that whole block.

```quiz
5(x + 2) − 3 = 2(x + 2) + 18. What is the value of x + 2?
* 7
- 5 :: Trap: that's x. The question asks for x + 2.
- 21 :: That's 3(x + 2). Divide by 3.
> Call x + 2 "u": 5u − 3 = 2u + 18, so 3u = 21 and u = 7.
```
