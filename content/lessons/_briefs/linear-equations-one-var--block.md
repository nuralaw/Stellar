# linear-equations-one-var--block

**Shows:** when the same group (like \(x - 4\)) repeats, you can wrap it in a box, solve for the box, and never solve for \(x\).

**Storyboard:**
1. \(3(x - 4) + 2 = 20\) appears. The group \(x - 4\) is highlighted.
2. The group shrinks into a solid box labelled "block": \(3[\;] + 2 = 20\). The question strip below reads "Find \(x - 4\)".
3. Solve the box: \(3[\;] = 18\), then \([\;] = 6\). The box lights up with "6".
4. The question strip and the box merge: "\(x - 4 = 6\)" with a check mark. A faded side path "find \(x\) first = extra steps" shows \(x = 10\) and is struck through.
5. Second mini-scene: \(9(E) + 2 = 8(E) + 18\) with E boxes; subtract 8 boxes: one box left, \(E = 16\).

**Labels & formulas:** "block", \(3(x - 4) + 2 = 20\), \(3[\;] = 18\), \(x - 4 = 6\), "no need for \(x\)".

**Stress:** the box is the accent colour from frame 2 on; the abandoned \(x\)-route is dim and crossed out. Keep the box big enough to hold "6" at phone width.
