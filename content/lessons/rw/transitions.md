# Name the link
Join the two ideas: and, but or so.

## Name the link first

Cover the choices. Join the sentence before the blank to the sentence after it with **and**, **but** or **so**.

```visual
transitions--buckets
```

```example
The test was easy. ______ most failed.
Choices: Therefore, / However, / Similarly,
1. Before the blank: the test was easy :: Read idea 1.
2. After the blank: most failed :: Read idea 2.
3. Easy, **but** most failed → contrast :: Join them: and, but or so?
4. Answer: However, :: The only contrast word.
```

```more
A **transition** is a word or phrase that shows how two ideas connect. *However* means but. *Therefore* means so. *Similarly* means and. Cover the choices first, so a choice cannot trick you. Then pick the choice from the same bucket.
```

## So means result

**So** points to *therefore*, *thus*, *as a result*.

```quiz
The bakery raised its prices by 30%. ______ many regular customers started buying bread elsewhere.
* As a result,
- However, :: Leaving is what you would expect after a price rise.
- For example, :: Leaving is not one case of a price rise.
- Similarly, :: Customers did not also raise prices.
> Prices went up, so customers left. Idea 2 is a result of idea 1.
```

## Use the sentence before

```quiz
Most visitors came for the beaches. Many of them left early because of the heat. ______ the café near the beach stayed busy all day.
* However,
- As a result, :: You linked to sentence 1. Link to sentence 2.
- For example, :: The café is not one case of leaving early.
> The blank links to the sentence just before it. Visitors left early, but the café stayed busy: contrast.
```

# Example or Similarly
One case of the idea, or a second thing?

## One case = example

Idea 2 is one case of idea 1? *For example*. A second, separate thing alike? *Similarly*. The exact detail of idea 1? *Specifically*.

```example
Bees can see ultraviolet light. ______ some birds can detect it.
Choices: For example, / Similarly, / Therefore,
1. Idea 1: bees see ultraviolet :: Read idea 1.
2. Idea 2: some birds do as well :: Read idea 2.
3. Birds aren't bees: a second group, same ability :: One case, or a second thing?
4. Answer: Similarly, :: Two separate things act alike.
```

```more
**For example** and **For instance** bring one case from a group. **Similarly** and **Likewise** bring a second thing that is alike. **Specifically** gives the exact detail of the same idea: sentence 1 is general, sentence 2 says it precisely.
```

## One case or two things

```quiz
Many desert plants store water in their thick stems. ______ the saguaro cactus can swell with hundreds of liters of water after a single storm.
- Similarly, :: The saguaro is a desert plant, not a separate thing.
* For example,
- Therefore, :: Other plants do not cause the saguaro to swell.
- However, :: The saguaro does just what sentence 1 says.
> Idea 1 is general: many desert plants. Idea 2 is one plant doing exactly that.
```

## Say it exactly

```quiz
The survey has one serious flaw. ______ it asked only people who already owned bicycles.
* Specifically,
- However, :: Sentence 2 does not turn against sentence 1. It explains it.
- Similarly, :: The flaw is not a second, separate thing.
> Sentence 1 says "one serious flaw" without details. Sentence 2 says exactly what it is.
```

# In fact or reworded
A stronger new fact, or the same thing again?

## In fact goes further

*In fact* makes idea 1 stronger. *In other words* only repeats it, with no new facts.

```example
The café is cash-only. ______ it doesn't take cards.
Choices: In fact, / In other words, / However,
1. Idea 1: cash-only :: Read idea 1.
2. Idea 2: no cards :: Read idea 2.
3. No cards = cash-only. Nothing new :: New fact, or a rewording?
4. Answer: In other words, :: Same idea, new words.
```

```more
**In fact** and **Indeed** add a stronger or more surprising fact to the same idea. **In other words** and **That is** say the same idea again in simpler words. Ask: does sentence 2 give me anything new? If not, it is a rewording.
```

## New fact or rewording

```quiz
The new phone's battery lasts a long time. ______ in lab tests, it ran for three full days on a single charge.
- In other words, :: Three days is a new fact, not a rewording.
* In fact,
- However, :: Three days supports "a long time". There is no contrast.
- Similarly, :: It is the same battery, not a second thing.
> Idea 2 backs up "a long time" with a striking number. Stronger version: *In fact*.
```

# Concession
Admit a point, then turn back.

## Admit, then turn

A concession admits a point against the writer's view. The next sentence turns back with *Still* or *Even so*.

```example
______ the café is small. Still, its coffee is the best in town.
Choices: Admittedly, / Therefore, / Similarly,
1. After the blank: "Still, its coffee is the best" :: It turns back. Look forward.
2. So sentence 1 admits a weakness :: Small is a weakness.
3. Answer: Admittedly, :: It admits the weakness first. *Granted* works too.
```

```more
**Admittedly**, **Granted** and **Of course** mean "I agree this is true, but...". **Still**, **Even so** and **Nevertheless** mean "but this is true anyway". Both kinds belong in the *but* bucket. The first admits a point, and the second turns back.
```

## Turn back

```quiz
The recipe takes three hours. ______ most people agree the result is worth the wait.
* Even so,
- As a result, :: Three hours does not cause people to agree.
- In addition, :: The long wait is a cost, not one more good thing.
> Three hours is a cost. The good result turns back against it: *Even so*.
```

# Sequence
Time words put events in order.

## Before or after?

*Previously* looks back. *Later* looks forward. *Finally* ends a list. Check which event came first.

```example
The town now gets its power from the wind. ______ it burned coal for a hundred years.
Choices: Previously, / Later, / Therefore,
1. Sentence 1: power from wind, now :: The present.
2. Sentence 2: burned coal for a century :: An earlier time.
3. Now → before: it looks back :: Which direction in time?
4. Answer: Previously, :: *Later* would point forward.
```

```more
Sequence words show time order. Looking back: *Previously*, *Earlier*, *Before that*. Looking forward: *Later*, *Afterward*, *Eventually*. Ending a list: *Finally*. Put the two events on a time line. Which one came first?
```

## Which came first?

```quiz
Maya joined the school choir in September. By May, she was singing a solo. ______ she was chosen to lead the choir's spring tour.
* Later,
- Previously, :: Leading the tour happens after the solo, not before.
- For example, :: Leading the tour is not one case of singing a solo.
> The events go in time order: joined, then solo, then tour. The tour is later.
```

# Phrase transitions
Read every word. Does it support or undermine?

## Test each word

Some transitions are phrases. Test every word: does the new idea support, undermine or add to the old one?

```example
Many people thought heavy traffic broke the bridge. ______ engineers found cracks that were older than the traffic.
Choices: Undermining this view, / Confirming this view, / Repeating this view,
1. Idea 1: traffic broke the bridge :: A view, or explanation.
2. Idea 2: cracks older than the traffic :: Traffic can't be the cause.
3. The new fact **weakens** the view :: Support, or undermine?
4. Answer: Undermining this view, :: Every word in it is true.
```

```more
In a phrase transition, each word carries meaning. **Undermine** means to weaken. **Confirm** means to show that something is true. **Contrary to** means opposite to. Do not choose by the first word only. Read the whole phrase and check it against the text.
```

## Support or weaken?

```quiz
A physician proposed that an illness spreads through drinking water. ______ later tests found the same germ in water from every village that had the illness.
- Contradicting this hypothesis, :: The germ in the water agrees with the proposal.
* Confirming this hypothesis,
- Ignoring this hypothesis, :: The tests are about the proposal. They do not ignore it.
> The germ was found in the water, as proposed. The new fact supports the hypothesis.
```

# Trap: Moreover
Moreover only adds. Look for a sharper link.

## Don't pick Moreover

*Moreover* only adds one more point. Pick it only when idea 2 is just one more point: no contrast, result, example or time order.

```example
The bridge is a century old. ______ it still carries heavy trucks every day.
Choices: Moreover, / Nevertheless, / For example,
1. Idea 1: a century old :: Read idea 1.
2. Idea 2: still carries heavy trucks :: Read idea 2.
3. Old, **but** still in heavy use → contrast :: Test and, but, so first.
4. Answer: Nevertheless, :: A sharper link beats *Moreover*.
```

```more
*Moreover* and *Additionally* sound safe because they fit almost any text. That is why they are traps. On the SAT, the right answer names the real link: contrast, result, example or time. Choose *Moreover* only when the second idea truly is one more point of the same kind.
```

## Beat the trap

```quiz
Fresh snow reflects most of the sunlight that hits it. This reflected light can be stronger than the light that comes straight down from the sky onto the slopes. ______ skiers can get sunburned even on freezing days.

Which choice completes the text with the most logical transition?
- Moreover, :: Trap: the reflected light causes the sunburn.
* As a result,
- However, :: The reflected light explains the sunburn. There is no contrast.
- Similarly, :: Skiers are not a second thing that reflects light.
> Snow reflects sunlight, so skiers burn. That is a result, not just one more fact.
```
