# One multiplier
Up 20%: × 1.2. Down 20%: × 0.8.

## Percent to multiplier

**Up 20%: × 1.2. Down 20%: × 0.8.** Start at 100%, then add or subtract the percent.

```visual
percentages--multiplier
```

```example
A ticket costs $50. The price rises 20%. What is the new price?
1. 100% + 20% = 120% = 1.2 :: The old price is 100%. Add the rise.
2. 50 × 1.2 = 60 :: Multiply the old price.
3. New price: $60
```

```more
100% means the whole old amount. To change a percent into a number, divide by 100: 120% = 1.2 and 80% = 0.8. A rise over 100% still starts at 100%: up 150% is 100% + 150% = 250%, so × 2.5, not × 1.5.
```

## 8% off? Keep 92%.

```quiz
A $25 shirt is 8% off. What is the sale price?
- $2 :: That is the discount. You pay what is left: 92%.
- $5 :: 8% is 0.08, not 0.8. You keep 92%.
* $23
> 100% − 8% = 92%, so multiply by 0.92: 25 × 0.92 = 23.
```

## Rise of 150%

```quiz
A $40 stock rises 150%. What is its new price?
- $60 :: That is 150% *of* $40. A rise adds it to the original.
* $100
- $190 :: You added 150 dollars. 150% of $40 is $60.
> 100% + 150% = 250%, so multiply by 2.5: 40 × 2.5 = 100.
```

# Percent of a number
"Of" means ×. "Is" means =.

## Write it as an equation

**a is p% of b** means a = (p/100) × b. One of a, p or b is missing: solve for it.

```example
18 is 30% of what number?
1. 18 = (30/100) × b :: Use a = (p/100)b.
2. 18 = 0.3b :: 30 ÷ 100 = 0.3.
3. b = 18 ÷ 0.3 = 60
```

```more
Read the words as math: "is" becomes =, "of" becomes ×, "what number" becomes b. So "What percent of 80 is 20?" becomes (p/100) × 80 = 20. The percent is always the part ÷ the whole. A percent over 100% just means the part is bigger than the whole.
```

## What percent?

```quiz
What percent of 80 is 20?
answer: 25
- 4 :: You divided 80 by 20. Divide the part by the whole.
- 400 :: That is 80 ÷ 20 as a percent. Use 20 ÷ 80.
> (p/100) × 80 = 20, so p = 20 ÷ 80 × 100 = 25.
~ type \frac{20}{80}\cdot 100 :: Part ÷ whole × 100: 25.
```

## Over 100%

```quiz
A bag has 56 marbles. That is 140% of the number of marbles in a box. How many marbles are in the box?
* 40
- 78.4 :: You multiplied 56 by 1.4. The box is the whole: divide.
- 140 :: That is the percent. Solve 56 = 1.4b for b.
> 56 = 1.4b, so b = 56 ÷ 1.4 = 40.
~ type y=1.4x :: x is the box. The bag is 140% of it.
~ type y=56 :: The bag has 56 marbles.
~ zoom 0 80 0 80
~ point (40, 56) :: Click the crossing: x = 40.
```

# Chain two percents
Two statements share a. Set them equal.

## Same a, two percents

Both give a. Write a = (p/100)b and a = (q/100)c. Then compare b and c.

```visual
percentages--chain
```

```example
a is 60% of b. a is also 150% of c. c is what percent of b?
1. a = 0.6b and a = 1.5c :: Both equal a.
2. 0.6b = 1.5c :: Set them equal.
3. c = (0.6 ÷ 1.5)b = 0.4b :: Divide both sides by 1.5.
4. c is 40% of b
```

```more
Pick the value the question asks about first. Here c is a percent of b, so solve for c in terms of b. The bars show it: a is 60% of b. Since a is also 150% of c, c is 1 ÷ 1.5 of a. So c is 0.6 ÷ 1.5 = 0.4 of b.
```

## Chain it yourself

```quiz
A number x is 120% of y. The number x is also 30% of z. z is what percent of y?
answer: 400
- 25 :: That is y as a percent of z. Flip it.
- 36 :: Do not multiply the percents. Set 1.2y equal to 0.3z.
> 1.2y = 0.3z, so z = (1.2 ÷ 0.3)y = 4y. That is 400% of y.
~ type \frac{1.2}{0.3}\cdot 100 :: z ÷ y = 1.2 ÷ 0.3 = 4, so 400%.
```

# Going back
Know the result? Divide by the multiplier.

## Divide to go back

**old = new ÷ multiplier.**

```example
After a 10% discount, a bag costs $72. What was the original price?
1. old × 0.9 = 72 :: 10% off keeps 90%.
2. old = 72 ÷ 0.9 = 80 :: Divide by the multiplier.
3. Original price: $80
```

```more
Do not take 10% of $72. The 10% was taken from the old price, which is the number we do not know. So write old × 0.9 = 72 and divide. Check: 80 × 0.9 = 72.
```

## Before the raise

```quiz
After a 25% raise, Mia earns $60 an hour. What did she earn before?
- $45 :: You subtracted 25% of $60, not 25% of the old pay.
* $48
- $75 :: That is another 25% raise. Go back: divide by 1.25.
> old × 1.25 = 60, so old = 60 ÷ 1.25 = 48.
~ type y=1.25x :: x is the old pay. A 25% raise is × 1.25.
~ type y=60 :: The new pay.
~ zoom 0 80 0 80
~ point (48, 60) :: Click the crossing: x = 48.
```

# Percent change
new ÷ old is the multiplier.

## New over old

**new ÷ old** is the multiplier. 1.08 means up 8%. 0.92 means down 8%.

```example
A plant grows from 20 cm to 23 cm. What is the percent increase?
1. 23 ÷ 20 = 1.15 :: New over old.
2. 1.15 − 1 = 0.15 :: Subtract 1.
3. Up 15%
```

```more
Percent change = (new − old) ÷ old × 100. Always divide by the old value, the one you started with. Here: (23 − 20) ÷ 20 = 0.15 = 15%. A multiplier below 1 means a decrease: 0.8 is down 20%.
```

## How far did it fall?

```quiz
A store sold 50 umbrellas in March and 40 in April. By what percent did sales fall?
* 20%
- 25% :: You divided by 40, the new value. Divide by the old.
- 80% :: April is 80% of March. The fall is 100% − 80%.
> 40 ÷ 50 = 0.8, which is 0.2 below 1: a 20% fall.
~ type y=50(1-\frac{x}{100}) :: 50 falls by x percent.
~ type y=40 :: April's sales.
~ zoom 0 50 0 60
~ point (20, 40) :: Click the crossing: x = 20, a 20% fall.
```

## From a multiplier

```quiz
An item's original price is x dollars. Its sale price is 0.35x dollars. The sale price is a decrease of what percent from the original price?
answer: 65
- 35 :: That is the price you pay. The decrease is 100% − 35%.
- 0.65 :: That is the decrease as a decimal. Write it as a percent.
> The multiplier is 0.35, so the price fell by 1 − 0.35 = 0.65. That is a 65% decrease.
```

# Trap: adding percents
Two changes? Multiply the multipliers. Never add.

## Multiply, never add

Up 20%, then down 20%, does not cancel. **Multiply the multipliers.**

```visual
percentages--bars
```

```example
A $100 coat goes up 20%, then down 20%. What is the final price?
1. 100 × 1.2 = 120 :: Up 20%.
2. 120 × 0.8 = 96 :: Down 20% of the bigger price.
3. $96: a 4% loss, not $100
```

```more
The second 20% is taken from $120, not from $100: 20% of 120 is 24, so the price falls by $24, more than the $20 it rose. Always apply each change to the amount you have at that moment.
```

## Net change

```quiz
A price rises 50%, then falls 30%. What is the net change?
* Up 5%
- Up 20% :: Trap: 50 − 30. The 30% is taken from the bigger price.
- Up 105% :: 1.05 is the multiplier. Subtract 1 to get the change.
> 1.5 × 0.7 = 1.05, and 1.05 means up 5%.
```

## Say it like the SAT

```quiz
The value of a collector's coin increased by 40% from 2020 to 2021, and then decreased by 25% from 2021 to 2022. The coin was worth $200 in 2020. What was the value, in dollars, of the coin in 2022?
answer: 210
- 230 :: Trap: you used 40% − 25% = 15%. Multiply 1.4 × 0.75.
- 280 :: That is the value in 2021. Apply the 25% decrease too.
> 200 × 1.4 = 280, then 280 × 0.75 = 210.
~ type 200\cdot 1.4\cdot 0.75 :: Multiply the start by both multipliers: 210.
```
