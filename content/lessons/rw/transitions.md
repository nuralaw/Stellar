# Name the link
Join the two ideas: and, but or so.

## Name the link first

Cover the choices. Join the two ideas with **and**, **but** or **so**. Then pick the word that says exactly that.

```example
The test was easy. ______ most failed.
Therefore, / However, / Similarly,
1. Before the blank: the test was easy :: Read idea 1.
2. After the blank: most failed :: Read idea 2.
3. Easy, **but** most failed → contrast :: Join them: and, but or so?
4. Answer: However, :: The only contrast word.
```

## So means result

**So** points to *therefore*, *thus*, *as a result*.

```quiz
The bakery raised its prices by 30%. ______ many regular customers started buying bread elsewhere.
* As a result,
- However, :: Leaving is what you'd expect after a price rise.
- For example, :: Leaving isn't one case of a price rise.
- Similarly, :: Customers aren't a second thing that raised prices.
> Prices went up, so customers left. Idea 2 is a result of idea 1.
```

# Example or Similarly
One case of the idea, or a second thing?

## One case = example

Idea 2 is one case of idea 1? *For example*. *Similarly* needs a second, separate thing that acts alike.

```example
Bees can see ultraviolet light. ______ some birds can detect it.
For example, / Similarly, / Therefore,
1. Idea 1: bees see ultraviolet :: Read idea 1.
2. Idea 2: some birds do as well :: Read idea 2.
3. Birds aren't bees: a second group, same ability :: One case, or a second thing?
4. Answer: Similarly, :: Two separate things act alike.
```

## One case or two things

```quiz
Many desert plants store water in their thick stems. ______ the saguaro cactus can swell with hundreds of liters of water after a single storm.
- Similarly, :: The saguaro is a desert plant, not a separate thing.
* For example,
- Therefore, :: Other plants don't cause the saguaro to swell.
- However, :: The saguaro does just what sentence 1 says.
> Idea 1 is general: many desert plants. Idea 2 is one plant doing exactly that.
```

# In fact or reworded
A stronger new fact, or the same thing again?

## In fact goes further

*In fact* makes idea 1 stronger. *In other words* only repeats it, with no new facts.

```example
The café is cash-only. ______ it doesn't take cards.
In fact, / In other words, / However,
1. Idea 1: cash-only :: Read idea 1.
2. Idea 2: no cards :: Read idea 2.
3. No cards = cash-only. Nothing new :: New fact, or a rewording?
4. Answer: In other words, :: Same idea, new words.
```

## New fact or rewording

```quiz
The new phone's battery lasts a long time. ______ in lab tests, it ran for three full days on a single charge.
- In other words, :: Three days is a new fact, not a rewording.
* In fact,
- However, :: Three days supports "a long time". Nothing turns.
- Similarly, :: It's the same battery, not a second thing.
> Idea 2 backs up "a long time" with a striking number. Stronger version: *In fact*.
```

# The sentence before
The blank links to the sentence right before it.

## Link the sentence before

The blank links to the sentence just before it, not to an earlier one.

```example
Frogs were once common in the pond. Then a disease spread among them. ______ few frogs remain today.
However, / As a result, / For example,
1. Sentence 1: frogs were common :: Too far back. Skip it.
2. Sentence 2: a disease spread :: The sentence just before the blank.
3. Disease spread, **so** few remain → result :: Join it with sentence 3.
4. Answer: As a result, :: *However* links to sentence 1.
```

## Find the right sentence

```quiz
Scientists long believed that adult brains could not grow new nerve cells. However, studies in the 1990s found new cells forming in adult brains. ______ one later study suggested that a single brain region may add hundreds of new cells each day.
- However, :: You linked to sentence 1. Sentence 3 agrees with sentence 2.
* In fact,
- Instead, :: Nothing in sentence 2 gets replaced.
> Sentence 2: new cells do form. Sentence 3 pushes that further with a number.
```

# Trap: Moreover
It fits loosely anywhere. Look for a sharper link.

## The Moreover default

*Moreover* fits loosely anywhere. Pick it only when no sharper link works.

```example
The bridge is a century old. ______ it still carries heavy trucks every day.
Moreover, / Nevertheless, / For example,
1. Idea 1: a century old :: Read idea 1.
2. Idea 2: still carries heavy trucks :: Read idea 2.
3. Old, **but** still in heavy use → contrast :: Test and, but, so first.
4. Answer: Nevertheless, :: A sharper link beats *Moreover*.
```

## Beat the trap

```quiz
Fresh snow reflects most of the sunlight that hits it. ______ skiers can get sunburned even on freezing days.
- Moreover, :: Trap: the reflected light causes the sunburn.
* As a result,
- However, :: The reflected light explains the sunburn. Nothing turns.
- Similarly, :: Skiers aren't a second thing that reflects light.
> Snow reflects sunlight, so skiers burn. That's a result, not just one more fact.
```
