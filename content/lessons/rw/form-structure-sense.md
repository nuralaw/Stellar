# Match verb to subject
Cross out the extras. Match the true subject.

## Find the true subject

A verb matches its **subject**, not the nearest noun. Cross out *of* phrases and anything between commas. Only *and* makes a subject plural.

```example
The box of old maps ______ dusty. Choices: is / are
1. Cross out: of old maps :: The subject is never inside an "of" phrase.
2. Left: The box ______ dusty. :: Read what is left.
3. box = one thing :: One thing takes a singular verb.
4. Answer: is
```

## Extras between commas

```quiz
The lead scientist, along with two graduate students, ______ the glacier every summer.
* visits
- visit :: *Along with* adds an extra, not a second subject.
- are visiting :: Plural. The subject is one scientist.
> Cross out the part between the commas: "The lead scientist visits the glacier."
```

# Tense follows the clues
Dates and nearby verbs set the tense.

## Find the time clue

Dates and nearby verbs set the tense. Match them.

```example
In 1969, astronauts ______ on the Moon for the first time. Choices: land / landed / will land
1. Clue: In 1969 :: A finished past date.
2. Past form: landed :: *Land* is present. *Will land* is future.
3. Answer: landed
```

## Match the tense

```quiz
When the volcano erupted in 1980, ash ______ towns hundreds of miles away.
* covered
- covers :: Present tense. The eruption was in 1980.
- will cover :: Future. This already happened.
- has covered :: *Has covered* runs up to now, not 1980.
> *Erupted* and *in 1980* are past, so the blank is past too: *covered*.
```

# Its, it's, their
One thing: it. Owning: no apostrophe.

## Count, then test

One thing is *it*, several are *they*. Owning takes no apostrophe: *its*, *their*. *It's* means *it is*.

```example
The company moved ______ headquarters to Denver. Choices: its / it's / their
1. Owner: the company = one thing :: One thing is *it*. Rules out *their*.
2. Test: "moved it is headquarters" :: Nonsense, so not *it's*.
3. Answer: its
```

## Pick the pronoun

```quiz
The city library reopened ______ rooftop garden after a year of repairs.
- it's :: That reads "reopened it is rooftop garden."
* its
- their :: Plural. A library is one thing.
- they're :: Means *they are*: plural, and not owning.
> One library owns the garden: singular and owning, so *its*.
```

# Opening phrase, next noun
The opening phrase describes the noun right after it.

## Ask the phrase

After an opening describing phrase and a comma, the next noun must be the thing described.

```example
Reading the letter, ______ Choices: Maya began to smile. / a smile spread across Maya's face.
1. Ask: who was reading the letter? :: Maya. A smile can't read.
2. Maya comes right after the comma :: The phrase describes the next noun.
3. Answer: Maya began to smile.
```

## Who was raised there?

```quiz
Raised in a fishing village in Chile, ______
- the poet's early work is full of images of the sea. :: The noun is *work*. Work wasn't raised anywhere.
- images of the sea fill the poet's early work. :: This says the images were raised in a village.
* the poet filled her early work with images of the sea.
> Who was raised in the village? The poet. So *the poet* comes right after the comma.
```

# Trap: a verb comes later
Main verb already there? Use -ing.

## Read to the end

Subject already has a main verb later? Use *-ing*, not a second verb.

```example
The dog ______ in the yard belongs to my neighbor. Choices: barks / barking
1. Read on: belongs :: That's the main verb.
2. Core: The dog belongs to my neighbor. :: One subject, one main verb.
3. Answer: barking :: It only describes the dog.
```

## Spot the main verb

```quiz
The bridge ______ the two islands opened in 1932.
- connects :: Trap: *opened* is already the main verb.
* connecting
- has connected :: Also a main verb. The bridge can't have two.
> The core is "The bridge opened in 1932." *Connecting the two islands* only describes the bridge.
```
