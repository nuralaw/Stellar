# linear-functions--first-n-units

**Shows:** when the first price covers the first N units, only the units after N pay the second rate, so the rule is first price + rate × \((x - N)\), and testing \(x = N\) catches mistakes.

**Storyboard:**
1. A row of km boxes 1 to 5. The first two are merged into one wide box "$5 (first 2 km)". Boxes 3, 4, 5 each carry "$3".
2. A bracket under boxes 3–5 reads "\(d - 2\) extra km" (for \(d = 5\): 3 km). Formula builds: \(C(d) = 5 + 3(d - 2)\).
3. A mini-graph shows costs at \(d = 2, 3, 4, 5\): 5, 8, 11, 14. A dashed test arrow at \(d = 2\): "\(C(2) = 5\) ✓".
4. A faded wrong rule \(C = 5 + 3d\) shows \(C(2) = 11\) with a red cross, then fades.
5. Simplified rule \(C(d) = 3d - 1\); the line's dashed extension back to \(d = 0\) hits \(-1\) ("not a price").

**Labels & formulas:** "first 2 km: $5", "each extra km: $3", \(5 + 3(d - 2)\), \(C(2) = 5\), \(C(d) = 3d - 1\).

**Stress:** the merged first box is neutral; the extra km boxes and the \((d - 2)\) bracket in the accent; red only for the rejected \(5 + 3d\). Keep at most 5 boxes in a row; test arrow clearly readable.
